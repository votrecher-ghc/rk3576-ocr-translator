## 1. 概述

验证系统在长时间、高负载下的稳定性。

## 2. 测试项目

| 测试ID | 名称               | 条件                     | 时长   |
| ------ | ------------------ | ------------------------ | ------ |
| ST-001 | 连续运行测试       | 实时模式持续运行         | 72h    |
| ST-002 | 高温运行测试       | 环境温度 40°C            | 24h    |
| ST-003 | 快速模式切换       | 每秒切换实时/拍照        | 1h     |
| ST-004 | 内存泄漏检测       | 监控内存增长             | 72h    |
| ST-005 | 传感器断连恢复     | 周期性断开/连接传感器     | 1h     |
| ST-006 | 磁盘满测试         | 归档至磁盘满             | -      |

## 3. 判定标准

| 项目           | 标准                           |
| -------------- | ------------------------------ |
| 连续运行       | 72h 无崩溃/重启                |
| 内存增长       | 72h 增长 ≤ 1MB                 |
| 温度           | 结温 ≤ 85°C                    |
| 恢复           | 异常后 1s 内恢复               |
| 磁盘满         | 不崩溃，自动清理               |
