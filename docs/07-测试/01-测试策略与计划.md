## 1. 测试目标

- 功能正确性：各模块功能符合需求
- 性能达标：延迟/帧率/准确率满足指标
- 稳定性：72h 连续运行无异常
- 可靠性：异常场景能恢复/降级

## 2. 测试分层

| 层次       | 范围                         | 文档               |
| ---------- | ---------------------------- | ------------------ |
| 单元测试   | 函数/模块内部逻辑            | 02-单元测试用例.md |
| 集成测试   | 模块间接口与协作             | 03-集成测试用例.md |

| 外设验证   | 各硬件外设功能               | 06-外设功能验证.md |

## 3. 测试环境

- 目标板：鲁班猫3 RK3576
- 测试固件：release 版本
- 串口日志 + 网络调试
- 标准测试图像集（OCR 准确率）

## 4. 测试计划

| 阶段       | 测试类型   | 说明               |
| ---------- | ---------- | ------------------ |
| 开发阶段   | 单元测试   | 随开发进行         |
| 联调阶段   | 集成测试   | 模块联调后         |
| 发版前     | 全量测试   | 性能+压力+外设     |
| 发布后     | 回归测试   | 每次修改后         |

## 5. 准入准出标准

### 准入
- 代码编译通过
- 单元测试 100% 通过

### 准出
- 所有测试用例通过
- 性能指标达标
- 72h 压力测试无异常
- 无严重/致命缺陷
