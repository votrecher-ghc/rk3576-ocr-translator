## 1. 概述

逐项验证各硬件外设功能正常。

## 2. 验证清单

### IMX415 摄像头

| 编号 | 验证项         | 方法                       | 预期           |
| ---- | -------------- | -------------------------- | -------------- |
| PV-001 | 设备识别     | v4l2-ctl --list-devices    | /dev/video0    |
| PV-002 | 格式支持     | --list-formats-ext         | NV12 1080p/4K  |
| PV-003 | 采集测试     | --stream-mmap              | 正常出帧       |
| PV-004 | 曝光控制     | --set-ctrl=exposure        | 画面明暗变化   |

### AP3216C 环境光

| 编号 | 验证项     | 方法                          | 预期             |
| ---- | ---------- | ----------------------------- | ---------------- |
| PV-010 | 设备识别 | ls /sys/bus/iio/             | iio:deviceX      |
| PV-011 | 数据读取 | cat in_illuminance_raw       | 数值随光照变化   |
| PV-012 | I2C 通信 | i2cdetect -y 2               | 0x1E 存在        |

### ICM42688 IMU

| 编号 | 验证项     | 方法                          | 预期             |
| ---- | ---------- | ----------------------------- | ---------------- |
| PV-020 | 设备识别 | ls /sys/bus/iio/             | iio:deviceX      |
| PV-021 | 数据读取 | cat in_anglvel_x_raw         | 随转动变化       |
| PV-022 | SPI 通信 | spi-config                    | 通信正常         |
| PV-023 | WHO_AM_I | i2c/spi 读 0x75              | 返回 0x47        |

### ADT7410 温度

| 编号 | 验证项     | 方法                          | 预期             |
| ---- | ---------- | ----------------------------- | ---------------- |
| PV-030 | 设备识别 | ls /sys/bus/iio/             | iio:deviceX      |
| PV-031 | 温度读取 | cat in_temp_input            | 合理温度值       |

### PWM 风扇

| 编号 | 验证项     | 方法                          | 预期             |
| ---- | ---------- | ----------------------------- | ---------------- |
| PV-040 | PWM 导出 | echo 0 > export               | pwm0 出现        |
| PV-041 | 转速控制 | 设置不同占空比                | 转速变化         |

### 按键

| 编号 | 验证项     | 方法                          | 预期             |
| ---- | ---------- | ----------------------------- | ---------------- |
| PV-050 | 设备识别 | cat /proc/bus/input/devices   | 按键设备         |
| PV-051 | 事件测试 | evtest                        | 按键有事件       |
