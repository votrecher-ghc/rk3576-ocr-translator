## 1. 概述

定义系统性能测试指标、方法与基准数据。

## 2. 性能指标

| 指标             | 目标       | 测试方法           |
| ---------------- | ---------- | ------------------ |
| 实时翻译延迟     | ≤ 300ms    | 帧时间戳统计       |
| 预览帧率         | ≥ 30fps    | 帧计数             |
| OCR 推理延迟     | ≤ 50ms     | rknn_run 计时      |
| 翻译延迟         | ≤ 100ms    | 翻译函数计时       |
| CPU 占用         | ≤ 70%      | /proc/stat         |
| 内存占用         | ≤ 1.5GB    | /proc/meminfo      |
| 启动时间         | ≤ 10s      | 启动到首帧计时     |
| OCR 准确率       | ≥ 95%      | 标准测试集对比     |

## 3. 测试方法

```bash
# 帧率测试（统计 1 分钟帧数）
./perf_test --duration 60 --mode realtime

# 延迟测试（采集到显示的时间戳差）
./perf_test --latency

# CPU/内存（top 采样）
top -b -d 1 -n 60 | grep ocr_translate

# OCR 准确率（标准测试集）
./ocr_eval --dataset /test_images --groundtruth /labels.txt
```
