## 1. 概述

单元测试针对各模块函数级逻辑，使用 Ceedling/Unity 框架。

## 2. 测试框架

- 框架：Unity（C 单元测试）
- 组织：Ceedling
- 覆盖率：gcov

## 4. 用例模板

```c
void test_pipeline_create_normal(void) {
    pipeline_config_t cfg = {.width=1920, .height=1080, .format=V4L2_PIX_FMT_NV12, .buf_count=4};
    pipeline_handle_t *h = pipeline_create(&cfg);
    TEST_ASSERT_NOT_NULL(h);
    pipeline_destroy(h);
}

void test_pipeline_create_invalid_param(void) {
    pipeline_config_t cfg = {.width=0};
    pipeline_handle_t *h = pipeline_create(&cfg);
    TEST_ASSERT_NULL(h);
}
```
