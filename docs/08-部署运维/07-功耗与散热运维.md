## 1. 概述

监控设备功耗与温度，保证长期稳定运行。

## 2. 功耗监测

| 场景       | 功耗   | 说明           |
| ---------- | ------ | -------------- |
| 待机       | ~1.5W  | 仅预览         |
| 实时翻译   | ~3.5W  | OCR 持续推理   |
| 拍照翻译   | ~5W    | 4K 采集峰值    |

```bash
# 查看温度
cat /sys/bus/iio/devices/iio:device2/in_temp_input

# 查看 CPU 频率
cat /sys/devices/system/cpu/cpu*/cpufreq/scaling_cur_freq
```

## 3. 散热运维

- 定期检查风扇运转（每月）
- 清理风扇灰尘（每季度）
- 监控温度日志趋势
- 风扇故障时降频运行

## 4. 运维建议

- 环境温度建议 < 40°C
- 保证通风良好
- 避免阳光直射
- 异常高温立即停机检查
