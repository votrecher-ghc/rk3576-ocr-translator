## 1. 启动类故障

| 故障           | 可能原因         | 排查方法                     |
| -------------- | ---------------- | ---------------------------- |
| 不启动         | 固件损坏         | 重新烧录                     |
| 内核 panic     | dtb 不匹配       | 检查 dtb 版本                |
| 卡在 U-Boot    | bootargs 错误    | 串口检查环境变量             |
| 主程序不启动   | 启动脚本错误     | 检查 S50ocr_translate        |

## 2. 摄像头故障

| 故障           | 可能原因         | 排查方法                     |
| -------------- | ---------------- | ---------------------------- |
| 无 /dev/video0 | 驱动未加载       | dmesg \| grep imx415         |
| 无图像         | CSI 链路配置错误 | 检查 DPHY/ISP 配置           |
| 画面花屏       | 格式不匹配       | v4l2-ctl 检查格式            |
| 帧率低         | 曝光过长         | 检查环境光与曝光参数         |

## 3. 显示故障

| 故障           | 可能原因         | 排查方法                     |
| -------------- | ---------------- | ---------------------------- |
| 黑屏           | DRM 未初始化     | dmesg \| grep drm            |
| 画面撕裂       | VSync 未同步     | 检查 PageFlip 事件           |
| OSD 不显示     | Plane 配置错误   | 检查 Plane z-order           |

## 4. 传感器故障

| 故障           | 可能原因         | 排查方法                     |
| -------------- | ---------------- | ---------------------------- |
| I2C 设备找不到 | 地址/接线错误    | i2cdetect 探测               |
| SPI 通信失败   | 模式/频率错误    | 检查 spi-cpha/spi-max-freq   |
| 数据异常       | 驱动寄存器错误   | 检查 WHO_AM_I                |

## 5. 性能故障

| 故障           | 可能原因         | 排查方法                     |
| -------------- | ---------------- | ---------------------------- |
| 帧率低         | CPU 占用高       | top 检查                     |
| 延迟高         | NPU 推理慢       | 检查模型是否 INT8            |
| 温度过高       | 风扇故障         | 检查 PWM/风扇                |
| OOM            | 内存泄漏         | 长时间监控内存               |
