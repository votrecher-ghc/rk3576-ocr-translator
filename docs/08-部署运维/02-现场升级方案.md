## 1. 概述

现场升级方案，支持设备部署后的固件更新，保证升级安全可靠。

## 2. 升级方式

| 方式       | 说明                     | 适用场景       |
| ---------- | ------------------------ | -------------- |
| USB 升级   | 通过 USB 烧录工具        | 本地维护       |
| SD 卡升级  | 从 SD 卡自动升级         | 现场无 PC      |
| 网络 OTA   | 通过网络下载升级包       | 远程升级（可选）|

## 3. A/B 分区方案

采用 A/B 双分区，升级时写备用分区，切换启动：

| 分区      | 用途               |
| --------- | ------------------ |
| rootfs_a  | 主分区（当前运行） |
| rootfs_b  | 备用分区（升级用） |

## 4. 升级流程

```
1. 下载升级包到 /tmp
2. 校验签名
3. 写入备用分区（rootfs_b）
4. 设置下次启动从 rootfs_b
5. 重启
6. 启动成功后标记 rootfs_b 为活动
7. 失败则自动回滚到 rootfs_a
```

## 5. 回滚机制

- 升级后 3 次启动失败自动回滚
- U-Boot 维护启动计数器
