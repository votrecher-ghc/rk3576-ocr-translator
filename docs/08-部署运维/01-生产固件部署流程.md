## 1. 概述

生产固件部署流程，将完整系统固件烧录至设备 eMMC。

## 2. 部署前准备

- [ ] 固件版本确认（update.img）
- [ ] 烧录工具（upgrade_tool / RKDevTool）
- [ ] 设备数量清点
- [ ] 烧录记录表

## 3. 烧录流程

```
1. 设备断电
2. 按住 RECOVERY 键，连接 USB 上电 → 进入 Loader 模式
3. 执行烧录命令
   upgrade_tool uf update.img
4. 等待烧录完成（约 3-5 分钟）
5. 断电，拔掉 USB
6. 重新上电，验证启动
```

## 4. 部署后验证

- [ ] 串口能看到 U-Boot 启动日志
- [ ] 内核正常加载，无 panic
- [ ] 主程序自动启动
- [ ] 屏幕显示预览画面
- [ ] 按键拍照功能正常
- [ ] 记录设备编号与固件版本
