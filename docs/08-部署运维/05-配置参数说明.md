## 1. 概述

系统运行时配置参数说明，配置文件位于 `/ocr/conf/config.json`。

## 2. 配置文件

```json
{
    "preview_fps": 30,
    "ocr_interval_ms": 200,
    "brightness": 80,
    "fan_mode": 0,
    "fan_duty": 60,
    "src_lang": "en",
    "dst_lang": "zh",
    "eis_enable": true,
    "log_level": 2
}
```

## 3. 参数清单

| 参数             | 类型   | 默认值 | 说明               |
| ---------------- | ------ | ------ | ------------------ |
| preview_fps      | int    | 30     | 预览帧率           |
| ocr_interval_ms  | int    | 200    | OCR 间隔（ms）     |
| brightness       | int    | 80     | 显示亮度(%)        |
| fan_mode         | int    | 0      | 0:自动 1:手动      |
| fan_duty         | int    | 60     | 手动模式占空比(%)  |
| src_lang         | string | en     | 源语言             |
| dst_lang         | string | zh     | 目标语言           |
| eis_enable       | bool   | true   | 电子防抖开关       |
| log_level        | int    | 2      | 0:DEBUG~4:FATAL   |
