## 1. 日志来源

| 日志类型 | 位置/命令 | 说明 |
|---|---|---|
| 应用日志 | `/var/log/ocr_translator.log` | `config/ocr_translator.json` 的默认路径 |
| 前台日志 | stderr | 未启用文件输出或文件初始化失败前的诊断 |
| 服务日志 | `logread` 或 init 脚本重定向位置 | 取决于目标 Buildroot 日志方案 |
| 内核日志 | `dmesg` | 驱动、IIO、V4L2、DRM、PWM 和 deferred probe |

应用日志级别为 `debug/info/warn/error/fatal`，也可用 `LOG_LEVEL` 环境变量覆盖。

## 2. 日志格式

```text
[2026-07-16 14:30:22.123][I][ocr_translator][main.c:600 run_loop] frame processed
```

字段依次为：

- 实时时钟和毫秒；
-级别；
- 模块名；
- 源文件、行号和函数；
- 消息正文。

## 3. 常用诊断

```bash
# 应用日志
tail -F /var/log/ocr_translator.log

# 内核和服务日志
dmesg | tail -n 200
logread 2>/dev/null | tail -n 200

# 进程与资源
ps | grep '[o]cr_translator'
cat /proc/meminfo
cat /proc/loadavg

# IIO 设备
for d in /sys/bus/iio/devices/iio:device*; do
    [ -r "$d/name" ] && printf '%s: %s\n' "$d" "$(cat "$d/name")"
done

# ADT7410 温度
TEMP="$(
    for d in /sys/bus/iio/devices/iio:device*; do
        [ "$(cat "$d/name" 2>/dev/null)" = adt7410 ] && printf '%s\n' "$d"
    done
)"
[ -n "$TEMP" ] && cat "$TEMP/in_temp_input"

# input capability
cat /proc/bus/input/devices

# 摄像头和显示
media-ctl -p
v4l2-ctl --device=/dev/video0 --all
modetest -c -p
```

仓库当前没有 `ocr_diag` 命令，不要把不存在的诊断工具写入运维流程。

## 4. 重点日志

排障时优先查找：

```bash
grep -Ei 'error|failed|timeout|stalled|cleanup|rollback|overflow|deferred' \
    /var/log/ocr_translator.log
dmesg | grep -Ei 'ocr|rknn|rga|drm|v4l2|iio|pwm|deferred|conflict'
```

需要记录的板端证据：

- 应用版本/commit；
- SDK、kernel、librga、librknnrt 与 RKNN Toolkit2 版本；
- 配置文件 checksum；
- 模型 `model_artifacts.sha256`；
- `media-ctl -p` 与 `modetest -c -p`；
- 失败前后完整日志，而不是只截最后一行。
