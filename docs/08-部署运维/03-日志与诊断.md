## 1. 概述

系统日志记录运行状态与异常信息，用于故障诊断。

## 2. 日志配置

| 日志类型   | 路径                  | 说明           |
| ---------- | --------------------- | -------------- |
| 应用日志   | /ocr/data/log/app.log | 主程序日志     |
| 内核日志   | dmesg                 | 内核日志       |
| 系统日志   | /var/log/messages     | 系统服务       |

日志级别：DEBUG / INFO / WARN / ERROR / FATAL

## 3. 日志格式

```
[2026-07-10 14:30:22] [INFO] [pipeline] frame acquired, index=0, ts=1234567890
[2026-07-10 14:30:22] [ERROR] [ai] rknn_run failed: -7
```

## 4. 诊断命令

```bash
# 查看应用日志
tail -f /ocr/data/log/app.log

# 内核日志
dmesg | tail

# 系统状态
cat /proc/meminfo
cat /proc/loadavg

# 温度
cat /sys/bus/iio/devices/iio:device2/in_temp_input

# 各模块状态（通过 comm）
ocr_diag --status
```
