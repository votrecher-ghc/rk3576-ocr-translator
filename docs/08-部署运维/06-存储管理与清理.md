## 1. 概述

存储管理保证 eMMC 空间合理使用，避免磁盘满导致故障。

## 2. 存储分区

| 分区     | 大小   | 用途           | 清理策略       |
| ---------- | ------ | -------------- | -------------- |
| rootfs     | 2GB    | 系统           | 不清理         |
| app        | 1GB    | 应用           | 不清理         |
| models     | 512MB  | 模型           | 不清理         |
| data       | 剩余   | 归档/日志/配置 | 按策略清理     |

## 3. 归档清理策略

- 容量上限：500MB
- 数量上限：1000 条
- 超限时删除最旧记录
- 每次拍照后检查

```bash
# 手动清理
ocr_archive --cleanup --max-size 500 --max-count 1000
```

## 4. 日志轮转

- 单文件最大 10MB
- 保留 5 个历史文件
- 使用 logrotate 或应用内实现
