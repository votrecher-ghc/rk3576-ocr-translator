## 1. 概述

将 U-Boot、内核、根文件系统、应用打包为完整固件，通过烧录工具写入 eMMC。

## 2. 固件打包

```bash
# 使用 mkfirmware.sh 打包
./mkfirmware.sh
# 产物：update.img（统一固件）
```

`package-file` 示例：
```
package-file
update.img    update
bootloader    idbloader.img
bootloader    u-boot.itb
boot          boot.img
rootfs        rootfs.img
app           app.img
models        models.img
```

## 3. 烧录工具

- **upgrade_tool**（Linux 命令行）
- **RKDevTool**（Windows GUI）

## 4. 烧录步骤

```bash
# 进入 Loader 模式（按住 RECOVERY 键上电）
# 烧录统一固件
upgrade_tool uf update.img

# 或单独烧录分区
upgrade_tool ul idbloader.img
upgrade_tool ub u-boot.itb
upgrade_tool di boot boot.img
upgrade_tool di rootfs rootfs.img
```

## 5. 分区镜像

| 镜像         | 分区    | 说明           |
| ------------ | ------- | -------------- |
| idbloader.img | -      | Loader         |
| u-boot.itb   | uboot   | U-Boot         |
| boot.img     | boot    | 内核+dtb       |
| rootfs.img   | rootfs  | 根文件系统     |
| app.img      | app     | 应用程序       |
| models.img   | models  | RKNN 模型      |
