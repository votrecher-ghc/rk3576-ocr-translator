## 1. 概述

`build.sh` 一键完成 U-Boot、内核、Buildroot、应用、模型的构建与固件打包。

## 2. 脚本使用

```bash
# 全量构建
./build.sh all

# 单独构建
./build.sh uboot
./build.sh kernel
./build.sh buildroot
./build.sh app
./build.sh models

# 打包固件
./build.sh firmware

# 清理
./build.sh clean
```

## 3. 构建流程

```
1. 检查环境与依赖
2. 构建 U-Boot → idbloader.img, u-boot.itb
3. 构建 Kernel → Image, dtb, dtbo
4. 构建 Buildroot → rootfs.img
5. 构建应用 → ocr_translate + .so
6. 转换模型 → .rknn
7. 组装 rootfs（注入应用/模型/配置）
8. 打包 → update.img
```

## 4. 配置文件

```bash
# build.conf
export CROSS_COMPILE=aarch64-linux-gnu-
export ARCH=arm64
export JOBS=$(nproc)
export UBOOT_DIR=../u-boot
export KERNEL_DIR=../kernel
export BUILDROOT_DIR=../buildroot
export APP_DIR=../ocr
export OUTPUT_DIR=output
```

## 5. 常用命令

```bash
./build.sh all          # 全量构建
./build.sh app          # 仅构建应用（开发常用）
./build.sh firmware     # 重新打包固件
./build.sh clean all    # 清理所有
./build.sh clean app    # 仅清理应用
```
