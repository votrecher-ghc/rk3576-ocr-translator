## 1. 概述

本文档说明搭建 RK3576 端侧 OCR 翻译系统开发环境的步骤，包括主机配置、交叉编译工具链、源码获取等。

## 2. 主机环境要求

| 项目       | 要求                           |
| ---------- | ------------------------------ |
| 操作系统   | Ubuntu 22.04 LTS (x86_64)      |
| CPU        | 4核+                           |
| 内存       | 8GB+                           |
| 磁盘       | 100GB+ 空闲                    |
| 网络       | 可访问 GitHub                  |

## 3. 工具链安装

```bash
# 基础工具
sudo apt update
sudo apt install -y build-essential git wget curl cmake python3 python3-pip

# 交叉编译工具链（Buildroot 生成或使用预编译）
sudo apt install -y gcc-aarch64-linux-gnu g++-aarch64-linux-gnu

# 其他工具
sudo apt install -y device-tree-compiler u-boot-tools mtools parted
```

## 4. 源码获取

```bash
# U-Boot
git clone https://github.com/rockchip-linux/u-boot.git

# Kernel
git clone https://github.com/rockchip-linux/kernel.git -b linux-6.1-stable

# Buildroot
git clone https://github.com/rockchip-linux/buildroot.git

# RKNPU2 SDK（含 RKNN Toolkit2）
git clone https://github.com/rockchip-linux/rknpu2.git
```

## 5. 依赖库安装

```bash
# Python 依赖（RKNN Toolkit2 模型转换）
pip3 install rknn-toolkit2 -i https://pypi.org/simple/

# Ubuntu 依赖
sudo apt install -y libdrm-dev libjson-c-dev
```

## 6. 环境验证

```bash
aarch64-linux-gnu-gcc --version
cmake --version
dtc --version
```
