## 1. CPU

| 核心     | 频率    | L2 Cache | 用途建议       |
| -------- | ------- | -------- | -------------- |
| A72 ×4   | 2.2GHz  | 1MB      | AI/翻译/主控   |
| A53 ×4   | 1.8GHz  | 512KB    | 采集/传感器    |

## 2. 内存与存储

| 资源       | 规格              |
| ---------- | ----------------- |
| DDR        | 4GB LPDDR4X       |
| CMA        | 256MB             |
| eMMC       | 32GB              |
| SD         | SD3.0             |

## 3. 摄像头接口

| 接口   | Lane | 速率          |
| ------ | ---- | ------------- |
| CSI0   | 4    | 1.5Gbps/lane  |
| CSI1   | 4    | 1.5Gbps/lane  |

## 4. 显示接口

| 接口   | 最大分辨率   |
| ------ | ------------ |
| HDMI   | 4K@60fps     |
| DSI    | 1080p        |
| RGB    | 1080p        |

## 5. 通信接口

| 接口   | 数量 | 备注           |
| ------ | ---- | -------------- |
| I2C    | 8    | I2C2 用于传感器|
| SPI    | 6    | SPI0 用于 IMU  |
| UART   | 10   | UART2 调试     |
| PWM    | 16   | PWM9 风扇      |
| PCIe   | 2    | NVMe 可选      |
| USB    | 3    | 1× 3.0 OTG     |

## 6. 地址映射

| 资源       | 物理地址           |
| ---------- | ------------------ |
| DDR        | 0x00000000         |
| CMA        | DDR 内预留         |
| 外设寄存器 | 0xFD000000+        |
