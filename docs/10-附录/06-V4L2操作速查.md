## 1. 概述

V4L2（Video4Linux2）是 Linux 视频采集框架，本项目用于 IMX415 摄像头采集。

## 2. 基本流程

```
open → S_FMT → REQBUFS → QUERYBUF(MMAP) → EXPBUF → QBUF → STREAMON
                                                                    │
                                                              DQBUF(获取帧)
                                                              QBUF(归还)
                                                                    │
                                                              STREAMOFF → close
```

## 3. 关键 ioctl

```c
// 设置格式
struct v4l2_format fmt;
ioctl(fd, VIDIOC_S_FMT, &fmt);

// 请求缓冲
struct v4l2_requestbuffers req;
ioctl(fd, VIDIOC_REQBUFS, &req);

// 查询缓冲
struct v4l2_buffer buf;
ioctl(fd, VIDIOC_QUERYBUF, &buf);

// 导出 DMA-BUF
struct v4l2_exportbuffer expbuf;
ioctl(fd, VIDIOC_EXPBUF, &expbuf);  // expbuf.fd 即 DMA-BUF fd

// 入队/出队
ioctl(fd, VIDIOC_QBUF, &buf);
ioctl(fd, VIDIOC_DQBUF, &buf);

// 流控
ioctl(fd, VIDIOC_STREAMON, &type);
ioctl(fd, VIDIOC_STREAMOFF, &type);
```

## 4. DMA-BUF 零拷贝

```c
// 1. V4L2 使用 MMAP 分配缓冲
req.memory = V4L2_MEMORY_MMAP;

// 2. 导出为 DMA-BUF fd
ioctl(fd, VIDIOC_EXPBUF, &expbuf);
// expbuf.fd 可传给 RGA/DRM/RKNN

// 3. 或使用外部 DMA-BUF 作为输出（DMABUF 导入）
req.memory = V4L2_MEMORY_DMABUF;
buf.m.fd = external_dmabuf_fd;
```

## 5. 控制接口

```c
// 设置曝光
struct v4l2_control ctrl;
ctrl.id = V4L2_CID_EXPOSURE;
ctrl.value = target;
ioctl(fd, VIDIOC_S_CTRL, &ctrl);

// 设置增益
ctrl.id = V4L2_CID_ANALOGUE_GAIN;
ioctl(fd, VIDIOC_S_CTRL, &ctrl);

// 查询支持的控制
struct v4l2_queryctrl qctrl;
ioctl(fd, VIDIOC_QUERYCTRL, &qctrl);
```
