## 1. 数据流

RK3576 上采用 RGA 平移裁剪实现两轴电子防抖：

```text
ICM42688 IIO buffer (1 kHz, accel + gyro + timestamp)
        ↓
启动静止零偏校准 + IMU 到摄像头坐标变换
        ↓
Madgwick 四元数姿态 + 时间戳姿态历史
        ↓
按 V4L2 帧时间戳做四元数 SLERP
        ↓
真实姿态与平滑目标姿态之差
        ↓
绕 Y 轴角度 → 水平像素偏移 dx
绕 X 轴角度 → 垂直像素偏移 dy
        ↓
RGA 固定窗口裁剪并缩放到 DRM Buffer
```

RGA 只能完成窗口平移、裁剪和缩放，不能补偿绕摄像头 Z 轴产生的任意小角度画面旋转。完整 roll 和 rolling-shutter 补偿需要 GPU Homography 或 Mesh Warp。

## 2. 分辨率与固定窗口

默认配置：

```text
摄像头输入：1920 × 1080 NV12
固定裁剪：1600 × 900
显示输出：1280 × 720
固定放大倍率：1.2
```

居中时裁剪坐标为 `(160, 90)`，可用移动范围约为：

```text
水平方向：±160 像素
垂直方向：±90 像素
```

窗口大小保持不变，只改变 `crop_x/crop_y`，避免动态缩放产生画面“呼吸感”。

## 3. 姿态计算

`attitude_fusion.c` 在姿态积分前完成：

1. 使用 3×3 安装矩阵把 ICM42688 数据转换到摄像头坐标系。
2. 设备连续静止约 2 秒时估计陀螺仪零偏。
3. 从角速度中减去零偏。
4. 使用六轴 Madgwick 更新四元数。

摄像头坐标约定：

```text
X：图像向右
Y：图像向下
Z：镜头向前
```

默认安装矩阵是单位阵。实际硬件如果存在轴交换或符号翻转，应在初始化后调用：

```c
const float imu_to_camera[9] = {
    /* 根据 PCB 和摄像头安装方向填写 */
};
ocr_attitude_set_mount_matrix(&g_attitude, imu_to_camera);
```

应分别做左右转、上下转、绕镜头旋转三个单轴实验确认矩阵。

## 4. 帧时间戳对齐

每个成功更新的 IMU 四元数按 IIO 时间戳写入 `pose_history`。处理摄像头帧时，使用 `input->timestamp` 查询曝光时刻姿态；目标时间位于两个 IMU 样本之间时使用四元数 SLERP。

当前相机—IMU固定偏移定义在 `app/main/main.c`：

```c
#define EIS_CAMERA_IMU_OFFSET_NS INT64_C(0)
```

如果画面补偿方向正确但存在固定滞后、过冲或回摆，应通过图像运动曲线和陀螺仪曲线互相关标定该偏移。正值表示使用更晚的 IMU 姿态，负值表示使用更早的姿态。

## 5. 平滑目标姿态

防抖不再使用“当前姿态减上一帧姿态”。程序维护一个缓慢跟随真实姿态的虚拟摄像机：

```text
快速、小幅变化：目标姿态来不及跟随，形成反向补偿
持续、缓慢转动：目标姿态逐渐跟随，裁剪窗口返回中心
```

`filter_beta` 当前作为每帧目标姿态跟随系数：

```text
值越小：防抖更强，主动转动跟随更慢
值越大：防抖更弱，主动转动跟随更快
```

默认值为 `0.1`。RGA 层不再重复低通，避免两级滤波增加延迟。

## 6. 角度到像素

根据相机视场角计算像素焦距：

```text
fx = width  / (2 × tan(HFOV / 2))
fy = height / (2 × tan(VFOV / 2))
```

再计算：

```text
dx = -fx × tan(绕 Y 轴的补偿角)
dy = -fy × tan(绕 X 轴的补偿角)
```

代码当前使用 `HFOV=60°、VFOV=45°`。量产前应换成镜头实际标定得到的 `fx/fy` 或准确视场角。

## 7. RGA 应用

`rga_stabilizer.c` 根据固定 `scale` 计算裁剪尺寸，并保持输出宽高比：

```text
crop_x = center_x - dx
crop_y = center_y - dy
```

NV12 的 `crop_x/crop_y/crop_w/crop_h` 均进行偶数对齐，然后一次 RGA 操作完成裁剪和缩放。

## 8. 板端验证顺序

1. 启动后保持设备静止至少 2 秒，确认日志出现 `IMU gyro bias calibration complete`。
2. 只左右转动设备，确认主要改变 `crop_x`，且补偿方向相反。
3. 只上下转动设备，确认主要改变 `crop_y`。
4. 若轴错误，修改安装矩阵；若方向正确但延迟明显，调整 `EIS_CAMERA_IMU_OFFSET_NS`。
5. 检查静止时窗口是否漂移、快速运动时是否触边。
