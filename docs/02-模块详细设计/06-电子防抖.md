## 1. 概述

电子防抖模块利用 ICM42688 IMU 数据检测设备抖动，通过 RGA 对画面进行反向裁剪补偿，稳定预览和拍照画面。

## 2. IMU 数据采集

- 通过 IIO buffer 模式读取（高频率）
- 采样率：1kHz（陀螺仪 + 加速度计）
- 数据：6 轴浮点（gx,gy,gz,ax,ay,az）

## 3. 时间戳对齐

- IMU 数据与 V4L2 帧均带内核时间戳
- 对齐策略：取帧时间戳前后 N 个 IMU 样本做积分
- 容差：±2ms

## 4. 抖动补偿算法

```
1. 陀螺仪积分 → 累积旋转角
2. 低通滤波 → 去除高频噪声
3. 计算补偿 crop offset (dx, dy)
4. 限制补偿范围（预留 10% 边距）
```

## 5. RGA 变换应用

```c
// 根据补偿量设置 RGA 裁剪区域
rga_buffer_t src = wrapbuffer_fd(capture_fd, ...);
im_rect src_rect = {
    .x = dx, .y = dy,
    .width = 1920 - margin, .height = 1080 - margin
};
imresize_rect(src, dst, src_rect, dst_rect);
```
