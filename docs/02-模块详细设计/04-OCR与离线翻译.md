## 1. 概述

AI 模块负责文字检测、文字识别（OCR）和离线机器翻译，使用 NPU 加速推理，无需联网。

## 2. OCR 流程

```
图像(DMA-BUF) → RGA预处理 → 文字检测(RKNN) → 文字识别(RKNN) → 文本
                                   │
                                   └→ 翻译 → 译文
```

- **文字检测**：DBNet，输出文字区域多边形
- **文字识别**：CRNN，输出文字字符串
- **后处理**：去重、排序、合并

## 3. RKNN 模型

| 模型            | 输入尺寸   | 精度  | 推理耗时 | 用途       |
| --------------- | ---------- | ----- | -------- | ---------- |
| ocr_det.rknn    | 320x320    | INT8  | ~15ms    | 文字检测   |
| ocr_rec.rknn    | 320x48     | INT8  | ~25ms    | 文字识别   |

模型通过 `rknn_init` 加载，`rknn_inputs_set` 传入 DMA-BUF fd，`rknn_run` 推理。

## 4. 翻译引擎

- 离线词典 + 统计翻译模型
- 支持中英双向
- 词典文件 mmap 加载，避免内存拷贝
- 翻译耗时 ~50-100ms

## 5. 性能指标

| 指标         | 目标       |
| ------------ | ---------- |
| 检测推理     | ≤ 15ms     |
| 识别推理     | ≤ 25ms     |
| 翻译         | ≤ 100ms    |
| OCR 准确率   | ≥ 95%      |
