## 1. 概述

拍照模块响应按键事件，切换至拍照模式，对高分辨率静态图像进行 OCR 与翻译，合成图文结果并归档存储。

## 2. 拍照流程

```
按键事件(短按) → Main切换拍照模式
  → V4L2切4K采集 → 捕获1帧
  → RGA预处理 → RKNN OCR(高精度)
  → 翻译 → 图文合成
  → 归档保存
  → 恢复实时预览模式
```

## 3. 结果合成

- 原图（4K）+ 翻译文本叠加
- 使用 RGA 将文本渲染到原图
- 生成 JPG（带翻译）+ TXT（纯文本）

## 4. 归档存储

```
/ocr/data/archive/
├── 20260710_143022.jpg    // 带翻译的图像
├── 20260710_143022.txt    // 原文+译文文本
└── 20260710_143022.json   // 元数据(时间/OCR结果/坐标)
```

- 文件名：时间戳
- 存储空间不足时自动清理最旧记录

## 5. 回看接口

- 通过 comm 模块查询归档列表
- 支持按时间范围检索
