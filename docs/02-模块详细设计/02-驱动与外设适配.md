## 1. 概述

本模块负责所有外设的 Linux 驱动适配，使内核正确识别并管理硬件，为用户态提供标准接口。

## 2. 外设驱动清单

| 外设       | 总线/子系统 | 驱动文件              | 用户态接口        |
| ---------- | ----------- | --------------------- | ----------------- |
| IMX415     | V4L2/CSI    | imx415.c              | /dev/video0       |
| AP3216C    | IIO/I2C     | ap3216c.c             | /sys/bus/iio/...  |
| ICM42688   | IIO/SPI     | icm42688.c            | /sys/bus/iio/...  |
| ADT7410    | IIO/I2C     | adt7410.c             | /sys/bus/iio/...  |
| PWM 风扇   | PWM/HWMon   | pwm-fan.c             | /sys/class/pwm/...|
| 按键       | Input/GPIO  | gpio-keys (内核内置)  | /dev/input/eventX |

## 3. 适配状态

| 外设     | 状态   | 说明                         |
| -------- | ------ | ---------------------------- |
| IMX415   | 已适配 | V4L2 + CSI 配置完成          |
| AP3216C  | 已适配 | IIO 驱动，支持环境光+距离    |
| ICM42688 | 已适配 | IIO 驱动，支持 buffer 模式   |
| ADT7410  | 已适配 | IIO 驱动                     |
| PWM 风扇 | 已适配 | PWM + hwmon                  |
| 按键     | 已适配 | gpio-keys 配置               |

## 4. 驱动源码组织

```
kernel/drivers/
├── media/i2c/imx415.c
├── iio/light/ap3216c.c
├── iio/imu/icm42688.c
├── iio/temperature/adt7410.c
└── hwmon/pwm-fan.c
```
