## 1. 概述

散热模块通过 ADT7410 监测板载温度，PWM 自动调节风扇转速，保证系统在安全温度范围内运行。

## 2. 温度采集

- ADT7410 通过 I2C 接入，IIO 驱动
- 精度：±0.5°C（-40~+125°C）
- 采样间隔：1s
- 读取 `/sys/bus/iio/devices/iio:deviceX/in_temp_input`（毫摄氏度）

## 3. 风扇调速策略

| 温度范围   | PWM 占空比 | 风扇状态   |
| ---------- | ---------- | ---------- |
| < 45°C     | 0%         | 关闭       |
| 45-55°C    | 30%        | 低速       |
| 55-65°C    | 60%        | 中速       |
| 65-75°C    | 80%        | 高速       |
| > 75°C     | 100%       | 全速       |

采用滞回控制（2°C 滞回），避免频繁启停。

## 4. 过温保护

- 温度 > 85°C：降低 NPU 频率（降频保护）
- 温度 > 90°C：停止 OCR 推理，仅显示预览
- 温度 > 95°C：系统关机保护

```bash
# 设置 PWM 占空比
echo $DUTY > /sys/class/pwm/pwmchip9/pwm0/duty_cycle
```
