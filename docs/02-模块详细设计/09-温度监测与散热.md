## 1. 概述

散热模块通过 ADT7410 监测板载温度，PWM 自动调节风扇转速，保证系统在安全温度范围内运行。

## 2. 温度采集

- ADT7410 通过 I2C 接入，IIO 驱动
- 精度：±0.5°C（-40~+125°C）
- 采样间隔：1s
- 按 IIO `name=adt7410` 动态发现设备，再读取 `in_temp_input`（毫摄氏度）；不能
  假定 `iio:deviceX` 编号

## 3. 风扇调速策略

| 温度范围   | PWM 占空比 | 风扇状态   |
| ---------- | ---------- | ---------- |
| < 45°C     | 0%         | 关闭       |
| 45-55°C    | 25%        | 低速       |
| 55-65°C    | 50%        | 中速       |
| 65-75°C    | 75%        | 高速       |
| > 75°C     | 100%       | 全速       |

采用 3°C 回差避免频繁启停。温度设备缺失或运行时读取失败时，应用将风扇切到
100% 故障安全档。

## 4. 过温保护

当前应用没有擅自实现 NPU 降频、停止推理或系统关机策略；这些动作需要与 vendor
thermal framework、产品温度额定值和数据保存策略共同验收。现阶段应用只负责四档
调速、传感器故障满速，以及明确报告 PWM 写入/清理失败。不要在应用运行时手工写
PWM sysfs。
