## 1. 概述

摄像头模块基于 IMX415 传感器，通过 MIPI-CSI 接口接入 RK3576 ISP，经 V4L2 框架输出 NV12 格式帧，并导出为 DMA-BUF 实现零拷贝。

## 2. IMX415 配置

| 参数       | 实时模式值 | 拍照模式值 |
| ---------- | ---------- | ---------- |
| 分辨率     | 1920x1080  | 3840x2160  |
| 帧率       | 30fps      | 单帧       |
| 格式       | NV12       | NV12       |
| CSI Lane   | 4-lane     | 4-lane     |

## 3. V4L2 采集链路

```
IMX415 → CSI-2 → ISP → V4L2(/dev/video0) → DMA-BUF
```

关键 V4L2 操作：S_FMT → REQBUFS → QUERYBUF(MMAP) → EXPBUF → QBUF → STREAMON

## 4. DMA-BUF 导出

使用 `VIDIOC_EXPBUF` 将 V4L2 MMAP 缓冲导出为 DMA-BUF fd，供 RGA/DRM/RKNN 直接导入。

## 5. 帧率与分辨率

- 实时模式：1080p@30fps，缓冲 4 帧
- 拍照模式：4K 单帧，缓冲 2 帧
- 模式切换时需 STREAMOFF→修改格式→STREAMON

## 6. 曝光控制

通过 `VIDIOC_S_CTRL` 设置 exposure 和 gain，由自适应亮度模块动态调整。
