## 1. 概述

显示模块基于 DRM/KMS，使用多 Plane 实现视频预览与翻译文本的硬件叠加，VSync 同步避免撕裂。

## 2. DRM/KMS 资源

| 资源       | 说明                         |
| ---------- | ---------------------------- |
| CRTC       | 显示扫描控制器               |
| Connector  | HDMI 输出                    |
| Plane 0    | 视频层（NV12 预览画面）      |
| Plane 1    | OSD 层（ARGB8888 翻译文本）  |

## 3. Plane 分配

```
CRTC ─┬─ Plane0 (视频层, NV12)    ← RGA 显示输出
      └─ Plane1 (OSD层, ARGB8888) ← 翻译文本渲染
           │
           └─ HDMI Connector
```

## 4. 显示流程

```
RGA输出(DMA-BUF) → AddFB2 → SetPlane0 → PageFlip → VSync等待
翻译文本 → 渲染到缓冲(DMA-BUF) → AddFB2 → SetPlane1
```

## 5. OSD 叠加

- 翻译结果渲染为 ARGB8888 位图
- 使用 RGA 进行文本位图合成
- OSD 缓冲独立于视频缓冲，避免互相阻塞
