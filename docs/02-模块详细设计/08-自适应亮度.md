## 1. 概述

自适应亮度模块根据 AP3216C 环境光传感器数据，动态调节屏幕背光亮度，提高户外强光环境下的显示可读性。摄像头曝光由 IMX415 硬件 AE 自动处理，不参与联动。

## 2. 环境光采集

- 通过 IIO sysfs 读取 AP3216C 环境光值（lux）
- 采样间隔：500ms
- 滑动平均滤波（窗口 5）

## 3. 显示亮度调节

- 通过 backlight sysfs 调节屏幕背光
- 范围：亮度 10%~100%
