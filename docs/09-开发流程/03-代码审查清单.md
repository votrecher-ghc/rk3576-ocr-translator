## 1. 概述

代码审查清单，确保代码质量与安全。

## 2. 审查清单

### 功能正确性
- [ ] 逻辑符合需求
- [ ] 边界条件处理
- [ ] 错误码正确返回

### 内存安全
- [ ] 无内存泄漏（malloc/free 配对）
- [ ] 无缓冲区溢出
- [ ] 无悬垂指针
- [ ] DMA-BUF 引用计数正确

### 并发安全
- [ ] 共享数据加锁
- [ ] 无死锁风险
- [ ] 锁持有时间短

### 性能
- [ ] 无不必要的内存拷贝
- [ ] 热路径无系统调用
- [ ] 缓冲池预分配

### 编码规范
- [ ] 命名符合规范
- [ ] 注释完整
- [ ] 无 magic number

### 安全
- [ ] 输入校验
- [ ] 无命令注入
- [ ] 文件路径安全

## 3. 审查流程

```
1. 开发者提交 PR/MR
2. 至少 1 名审查者审查
3. 修改后重新审查
4. 审查通过 → 合并
```
