## 1. 概述

统一代码风格，提高可读性与可维护性。

## 2. C 语言规范

- 标准：C11
- 缩进：4 空格
- 行宽：100 字符
- 大括号：K&R 风格

```c
int func(int a) {
    if (a > 0) {
        return a;
    }
    return -a;
}
```

## 3. 命名规范

| 类型     | 风格          | 示例             |
| -------- | ------------- | ---------------- |
| 函数     | snake_case    | pipeline_init    |
| 变量     | snake_case    | frame_count      |
| 宏       | UPPER_CASE    | MAX_BUFS         |
| 类型     | snake_case_t  | dma_buf_t        |
| 全局变量 | g_ 前缀       | g_pipeline_ctx   |

## 4. 注释规范

- 文件头：文件用途、作者、许可证
- 函数：Doxygen 风格

```c
/**
 * @brief 获取一帧图像
 * @param h 管线句柄
 * @param frame 输出帧
 * @param timeout_ms 超时(ms)
 * @return 0成功，负数错误码
 */
int pipeline_acquire_frame(pipeline_handle_t *h, pipeline_frame_t *frame, int timeout_ms);
```

## 5. 文件组织

- 头文件使用 `#pragma once`
- 源文件与头文件同名
- 每个模块独立目录
