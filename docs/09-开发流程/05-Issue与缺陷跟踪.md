## 1. 概述

使用 Git 平台 Issue 系统跟踪缺陷与任务。

## 2. 缺陷等级

| 等级   | 说明                   | 响应时间   |
| ------ | ---------------------- | ---------- |
| P0     | 致命：系统不可用       | 立即       |
| P1     | 严重：核心功能不可用   | 24h        |
| P2     | 一般：非核心功能问题   | 3 天       |
| P3     | 轻微：体验问题         | 下版本     |

## 3. Issue 模板

```markdown
**标题**：[模块] 简要描述

**环境**：
- 固件版本：
- 复现步骤：

**预期**：

**实际**：

**日志**：
```

## 4. 处理流程

```
新建 Issue → 分配负责人 → 修复 → 验证 → 关闭
```

- P0/P1 需立即修复并发布补丁
- 修复后需回归测试
