## 1. 概述

鲁班猫3（LubanCat 3）是野火（EmbedFire）推出的基于瑞芯微 RK3576 SoC 的开发板，面向边缘 AI、机器视觉、工业控制等应用场景。

---

## 2. RK3576 SoC 规格

### 2.1 处理器

| 特性             | 规格                                                      |
| ---------------- | --------------------------------------------------------- |
| CPU              | 4× Cortex-A72 @2.2GHz + 4× Cortex-A53 @1.8GHz (big.LITTLE) |
| GPU              | Mali-G52 MC3                                              |
| NPU              | 6 TOPS @INT8（支持 INT4/INT8/INT16/FP16）                |
| ISP              | 14bit ISP，4K HDR，最大 48MP                             |
| VPU              | H.265/H.264/AV1 解码 4K@60fps，H.265/H.264 编码 4K@60fps |

### 2.2 内存与存储

| 特性           | 规格                                   |
| -------------- | -------------------------------------- |
| 内存控制器     | LPDDR4/4X/LPDDR5                       |
| 鲁班猫3 配置   | 4GB LPDDR4X @2112MHz                   |
| eMMC           | 32GB eMMC 5.1                          |
| SD 卡          | SD 3.0（最高 UHS-I）                   |
| NVMe           | PCIe 2.1 ×2 lanes（可选）              |

### 2.3 显示接口

| 接口          | 规格                                    |
| ------------- | --------------------------------------- |
| HDMI          | HDMI 2.1，最大 4K@60fps                 |
| MIPI-DSI      | 4-lane，最高 1080p                      |
| RGB 并行      | 24-bit，最高 1920x1080                  |

### 2.4 摄像头接口

| 接口          | 规格                                    |
| ------------- | --------------------------------------- |
| MIPI-CSI      | 2× 4-lane（CSI0/CSI1）                  |
| DVP           | 8-bit 并行（可选）                      |
| DPHY          | 1.5Gbps/lane                            |

### 2.5 其他接口

| 接口          | 规格                                    |
| ------------- | --------------------------------------- |
| PCIe          | PCIe 2.1 ×2 lanes                      |
| USB           | USB 3.0 OTG ×1, USB 2.0 ×2             |
| 以太网        | GMAC（外接 PHY）                       |
| I2C           | 多路 I2C                                |
| SPI           | 多路 SPI                                |
| UART          | 多路 UART                               |
| PWM           | 多路 PWM                                |
| I2S/PDM/TDM   | 音频接口                                |

## 3. 板载资源

### 3.1 电源

| 项目         | 规格                           |
| ------------ | ------------------------------ |
| 输入电压     | DC 5V/4A（Type-C PD）          |
| PMIC         | RK860（瑞芯微电源管理）        |
| 上电时序     | PMIC 控制                      |

### 3.2 存储与内存

| 项目     | 规格                  |
| -------- | --------------------- |
| 内存     | 4GB LPDDR4X           |
| eMMC     | 32GB                  |
| SD 卡槽  | MicroSD ×1            |

### 3.3 网络

| 项目     | 规格                          |
| -------- | ----------------------------- |
| 以太网   | 千兆以太网（RTL8211F PHY）    |
| WiFi/BT  | 模组（可选 AP6256）           |

### 3.4 调试

| 项目         | 规格                           |
| ------------ | ------------------------------ |
| 调试串口     | UART2（Type-C USB 转串口）     |
| 调试 LED     | 电源 LED + 用户 LED            |
| 按键         | RESET + RECOVERY + 用户按键    |

## 4. 接口规格

### 4.1 USB 接口

| 接口       | 规格             | 用途               |
| ---------- | ---------------- | ------------------ |
| USB 3.0    | Type-C OTG       | 数据/供电/调试     |
| USB 2.0    | Type-A ×1        | 外设               |

### 4.2 显示接口

| 接口   | 规格              | 用途          |
| ------ | ----------------- | ------------- |
| HDMI   | 标准 HDMI 2.1     | 外接显示器    |
| DSI    | FPC 30pin         | MIPI 屏       |

### 4.3 摄像头接口

| 接口   | 规格                    | 用途            |
| ------ | ----------------------- | --------------- |
| CSI0   | FPC 22pin, 4-lane      | IMX415 摄像头   |
| CSI1   | FPC 22pin, 4-lane      | 副摄像头（可选）|

### 4.4 40Pin 扩展

标准 Raspberry Pi 兼容 40Pin 排针，详见 [02-引脚分配总表.md](02-引脚分配总表.md)。

## 6. 电气特性

### 6.1 电源域

| 电源域   | 电压   | 用途               |
| -------- | ------ | ------------------ |
| VCC_SYS  | 5V     | 系统主电源         |
| VCC_3V3  | 3.3V   | GPIO/外设          |
| VCC_1V8  | 1.8V   | I2C/SPI/部分 GPIO  |
| VDD_CPU  | 0.9V   | CPU 核心           |
| VDD_NPU  | 0.9V   | NPU 核心           |

### 6.2 GPIO 电平

| bank | 电平  | 备注                     |
| ---- | ----- | ------------------------ |
| GPIO0 | 3.3V | 系统控制                 |
| GPIO1 | 3.3V | 40Pin 默认 3.3V          |
| GPIO2 | 3.3V | 40Pin                    |
| GPIO3 | 1.8V/3.3V | 可配置               |
| GPIO4 | 3.3V | 40Pin                    |

### 6.3 I2C/SPI 电平

- I2C2: 3.3V（需上拉）
- SPI0: 3.3V
