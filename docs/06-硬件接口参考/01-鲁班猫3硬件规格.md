## 1. 概述

鲁班猫3（LubanCat 3）是野火（EmbedFire）推出的基于瑞芯微 RK3576 SoC 的开发板，面向边缘 AI、机器视觉、工业控制等应用场景。

> **文档状态（2026-07-16）**
>
> 本目录中的 I2C、SPI、PWM 和 GPIO 分配仍是项目接线候选，尚未完成目标板原理图、厂商 base DTS 与 40Pin 复用关系的联合验收。早期文档中的 `I2C2`、`PWM9` 和若干 GPIO 与当前 overlay 中的 `i2c4`、`pwm11`、`GPIO0_*` 候选并不一致。接线、上电或合并 overlay 前，必须以目标板具体硬件版本的原理图、40Pin 定义和实际 base DTS 为准。

## 2. RK3576 SoC 规格

### 2.1 处理器

| 特性             | 规格                                                      |
| ---------------- | --------------------------------------------------------- |
| CPU              | 4× Cortex-A72 @2.2GHz + 4× Cortex-A53 @1.8GHz (big.LITTLE) |
| GPU              | Mali-G52 MC3                                              |
| NPU              | 6 TOPS @INT8（支持 INT4/INT8/INT16/FP16）                |
| ISP              | 14bit ISP，4K HDR，最大 48MP                             |
| VPU              | H.265/H.264/AV1 解码 4K@60fps，H.265/H.264 编码 4K@60fps |

### 2.2 内存与存储

| 特性           | 规格                                   |
| -------------- | -------------------------------------- |
| 内存控制器     | LPDDR4/4X/LPDDR5                       |
| 鲁班猫3 配置   | 4GB LPDDR4X @2112MHz                   |
| eMMC           | 32GB eMMC 5.1                          |
| SD 卡          | SD 3.0（最高 UHS-I）                   |
| NVMe           | PCIe 2.1 ×2 lanes（可选）              |

### 2.3 显示接口

| 接口          | 规格                                    |
| ------------- | --------------------------------------- |
| HDMI          | HDMI 2.1，最大 4K@60fps                 |
| MIPI-DSI      | 4-lane，最高 1080p                      |
| RGB 并行      | 24-bit，最高 1920x1080                  |

### 2.4 摄像头接口

| 接口          | 规格                                    |
| ------------- | --------------------------------------- |
| MIPI-CSI      | 2× 4-lane（CSI0/CSI1）                  |
| DVP           | 8-bit 并行（可选）                      |
| DPHY          | 1.5Gbps/lane                            |

### 2.5 其他接口

| 接口          | 规格                                    |
| ------------- | --------------------------------------- |
| PCIe          | PCIe 2.1 ×2 lanes                      |

| 以太网        | GMAC（外接 PHY）                       |

## 5. 外设接口

### 5.1 本项目外设连接候选

| 外设          | 早期接线文档候选       | 当前 overlay 候选                     | 2026-07-16 状态 |
| ------------- | ---------------------- | ------------------------------------- | ---------------- |
| IMX415 摄像头 | MIPI-CSI0 / FPC 22pin  | 摄像头 overlay 默认不参与镜像构建     | media graph 与引脚未板端确认 |
| AP3216C       | I2C2，40Pin 3/5；IRQ 36 | `i2c4`；IRQ `GPIO0_PA1`               | 两组定义不一致，待核对 |
| ICM42688      | SPI0，40Pin 19/21/23/24；IRQ 22 | `spi0` CS0；IRQ `GPIO0_PB2`   | 总线相同但 IRQ 候选不同，待核对 |
| ADT7410       | I2C2，40Pin 3/5         | `i2c4`，与 AP3216C 共用               | 两组定义不一致，待核对 |
| PWM 风扇      | PWM9，40Pin 32          | `pwm11`，由用户态通过 sysfs 控制       | PWM 控制器候选不同，待核对 |
| 拍照按键      | GPIO1_A4 / 40Pin 7；另有早期 GPIO0_A6 记录 | `GPIO0_PC0`，低有效，`KEY_CAMERA` | 多组 GPIO 候选，待核对 |

当前 overlay 只表达软件集成候选，不等同于确认对应信号已经从 SoC 复用到指定 40Pin。尤其要检查 base DTS 中控制器标签是否存在、节点是否被其他功能占用、pinctrl 组是否匹配以及 I/O 电压域是否正确。

### 5.2 接口引脚详情

各外设详细接线见 [外设接线/](外设接线/) 目录。

## 6. 电气特性

### 6.1 电源域

| 电源域   | 电压   | 用途               |
| -------- | ------ | ------------------ |
| VCC_SYS  | 5V     | 系统主电源         |
| VCC_3V3  | 3.3V   | GPIO/外设          |
| VCC_1V8  | 1.8V   | I2C/SPI/部分 GPIO  |
| VDD_CPU  | 0.9V   | CPU 核心           |
| VDD_NPU  | 0.9V   | NPU 核心           |

### 6.2 GPIO 电平

| bank | 电平  | 备注                     |
| ---- | ----- | ------------------------ |
| GPIO0 | 3.3V | 系统控制                 |
| GPIO1 | 3.3V | 40Pin 默认 3.3V          |
| GPIO2 | 3.3V | 40Pin                    |
| GPIO3 | 1.8V/3.3V | 可配置               |
| GPIO4 | 3.3V | 40Pin                    |

### 6.3 I2C/SPI 电平

- 早期候选将传感器接到 I2C2，当前 overlay 候选改为 `i2c4`；实际总线电压与上拉方式必须查目标板原理图。
- 当前 ICM42688 overlay 候选使用 `spi0`，并分别声明 3.3V `vdd` 与 1.8V `vddio`；模块供电及逻辑电平必须按器件板卡设计核对，不能仅依据早期“SPI0 为 3.3V”的记录接线。
- GPIO/PWM 电平及容许电流必须以目标板对应电源域和扩展口规格为准；PWM 风扇不得直接由 SoC 引脚供电或驱动功率负载。
