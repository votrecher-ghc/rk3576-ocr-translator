## 1. 概述

鲁班猫3 提供 40Pin 扩展接口，本项目计划在扩展接口上连接 AP3216C、ICM42688、ADT7410、PWM 风扇和按键等外设。

> **重要：以下映射是早期接线候选，不是已验证 pinout。**
>
> 截至 2026-07-16，早期 40Pin 表与当前 overlay 存在总线、PWM 控制器和 GPIO 差异。使用前必须对照目标板硬件版本的官方原理图/40Pin 表，以及厂商内核的 base DTS、pinctrl 和电源域。不能直接照此表接线或据此判断 overlay 可用。

## 3. 各外设 GPIO 分配

| 信号       | RK3576 GPIO | 说明           |
| ---------- | ----------- | -------------- |
| MIPI_CLK±  | CSI0_CLK    | CSI 时钟       |
| MIPI_D0±   | CSI0_D0     | Lane 0         |
| MIPI_D1±   | CSI0_D1     | Lane 1         |
| MIPI_D2±   | CSI0_D2     | Lane 2         |
| MIPI_D3±   | CSI0_D3     | Lane 3         |
| I2C_SCL    | I2C4_SCL    | 传感器 I2C     |
| I2C_SDA    | I2C4_SDA    | 传感器 I2C     |
| RST_N      | GPIO3_A5    | 复位（低有效） |
| PWDN       | GPIO3_A4    | 待机（高有效） |

### 3.2 AP3216C 环境光（早期候选：I2C2）

| 信号    | 物理引脚 | RK3576 GPIO |
| ------- | -------- | ----------- |
| SDA     | 3        | GPIO1_A2    |
| SCL     | 5        | GPIO1_A3    |
| INT     | 36       | GPIO2_C0    |
| VCC     | 1        | 3.3V        |
| GND     | 25       | GND         |

当前 `ap3216c.dtso` 候选改为 `i2c4`，中断改为 `GPIO0_PA1`。该 overlay 没有证明 `i2c4` 或该 GPIO 已复用到上表物理引脚，必须先核对 base DTS 和原理图。

### 3.3 ICM42688 IMU（早期候选：SPI0）

| 信号    | 物理引脚 | RK3576 GPIO |
| ------- | -------- | ----------- |
| CSB     | 24       | GPIO1_B4    |
| SCLK    | 23       | GPIO1_B7    |
| SDI     | 19       | GPIO1_B6    |
| SDO     | 21       | GPIO1_B5    |
| INT1    | 22       | GPIO2_A0    |
| VCC     | 1        | 3.3V        |
| GND     | 20       | GND         |

当前 `icm42688-spi.dtso` 仍以 `spi0` CS0 为候选，但中断改为 `GPIO0_PB2`，与早期 `GPIO2_A0` / 40Pin 22 的记录不同。SPI pinctrl、片选冲突、IRQ 引脚和 1.8V/3.3V 电源域均需板端确认。

### 3.4 ADT7410 温度（早期候选：I2C2）

| 信号    | 物理引脚 | RK3576 GPIO |
| ------- | -------- | ----------- |
| SDA     | 3        | GPIO1_A2    |
| SCL     | 5        | GPIO1_A3    |
| VCC     | 1        | 3.3V        |
| GND     | 25       | GND         |

早期候选是与 AP3216C 共用 I2C2（不同地址）；当前 `adt7410.dtso` 与 `ap3216c.dtso` 则共同指向 `i2c4`。实际采用哪一路必须由原理图和 base DTS 决定。

### 3.5 PWM 风扇（早期候选：PWM9）

| 信号    | 物理引脚 | RK3576 GPIO |
| ------- | -------- | ----------- |
| PWM     | 32       | GPIO2_B4    |
| VCC     | 2        | 5V          |
| GND     | 34       | GND         |

当前 `pwm-fan.dtso` 候选只启用 `pwm11`，并加 `ocr,fan-pwm` 标记供用户态发现；它与早期 PWM9 / 40Pin 32 的记录不同。还必须使用晶体管或风扇驱动级，不能由 GPIO/PWM 引脚直接带载。

### 3.6 拍照按键（早期候选：GPIO1_A4）

| 信号    | 物理引脚 | RK3576 GPIO |
| ------- | -------- | ----------- |
| KEY     | 7        | GPIO1_A4    |
| VCC     | 1        | 3.3V        |
| GND     | 9        | GND         |

当前 `gpio-keys.dtso` 候选改用 `GPIO0_PC0`、低电平有效，并上报 `KEY_CAMERA`。另有早期文档记录过 `GPIO0_A6`，三组候选均未完成 40Pin 实板确认。

## 4. GPIO 复用说明

### 4.1 RK3576 引脚命名规则

```
GPIO{bank}_{group}{pin}
如 GPIO1_A2 = bank1, group A, pin 2
```

- bank: 0-4
- group: A/B/C/D
- pin: 0-7

### 4.2 候选差异汇总

| 功能 | 早期文档候选 | 当前 overlay 候选 | 合并前必须确认 |
| ---- | ------------ | ----------------- | -------------- |
| AP3216C / ADT7410 | I2C2，40Pin 3/5 | `i2c4` | 控制器标签、SDA/SCL pinctrl、上拉、电压、占用 |
| ICM42688 | `spi0` CS0，IRQ `GPIO2_A0` | `spi0` CS0，IRQ `GPIO0_PB2` | SPI pinctrl、CS0、IRQ 路由、供电电平 |
| 风扇 | PWM9，40Pin 32 | `pwm11` | PWM 输出物理脚、极性、驱动级、是否被占用 |
| 拍照按键 | `GPIO1_A4` / 40Pin 7；另有 `GPIO0_A6` 记录 | `GPIO0_PC0` | 物理脚、上拉、低有效、电压域 |

当前 overlay 未自行定义完整 pinctrl，因此即使 overlay 能编译或加载，也不能据此认定信号已经出现在期望的扩展口引脚。

### 4.3 电平注意事项

- I2C 上拉值、上拉电源域及板上是否已有上拉必须按原理图确定，4.7kΩ 仅可作为常见候选值。
- ICM42688 当前 overlay 分别声明 3.3V `vdd` 与 1.8V `vddio`；模块实际电平必须核对，不能直接按旧表假定 SPI 全部为 3.3V。
- GPIO 和 PWM 电压域、驱动能力及复用冲突必须查 base DTS 与原理图。
- 上电前先断电测量供电与地，确认无 5V 信号误接到低压 I/O；风扇使用外部驱动级并共地。
