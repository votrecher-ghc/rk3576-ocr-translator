## 1. 概述

鲁班猫3 提供 Raspberry Pi 兼容的 40Pin 扩展接口，本项目在此接口上连接 AP3216C、ICM42688、ADT7410、PWM 风扇和按键等外设。

## 4. GPIO 复用说明

### 4.1 RK3576 引脚命名规则

```
GPIO{bank}_{group}{pin}
如 GPIO1_A2 = bank1, group A, pin 2
```

- bank: 0-4
- group: A/B/C/D
- pin: 0-7

### 4.2 复用配置（pinctrl）

```dts
&pinctrl {
    i2c2_pins: i2c2-pins {
        rockchip,pins =
            <1 RK_PA2 2 &pcfg_pull_up>,   // I2C2_SDA
            <1 RK_PA3 2 &pcfg_pull_up>;   // I2C2_SCL
    };

    spi0_pins: spi0-pins {
        rockchip,pins =
            <1 RK_PB4 3 &pcfg_pull_up>,   // SPI0_CS0
            <1 RK_PB5 3 &pcfg_pull_up>,   // SPI0_MISO
            <1 RK_PB6 3 &pcfg_pull_up>,   // SPI0_MOSI
            <1 RK_PB7 3 &pcfg_pull_up>;   // SPI0_SCLK
    };

    pwm9_pins: pwm9-pins {
        rockchip,pins = <2 RK_PB4 5 &pcfg_pull_none>;
    };
};
```

### 4.3 电平注意事项

- I2C 总线必须接上拉电阻（4.7kΩ）
- SPI 电平为 3.3V，注意与 1.8V 外设电平转换
- GPIO 默认 3.3V，GPIO3 可配置 1.8V
