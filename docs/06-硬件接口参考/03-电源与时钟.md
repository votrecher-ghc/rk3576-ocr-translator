## 1. 概述

本文档描述 RK3576 与鲁班猫3 的电源和时钟架构。

## 2. 电源架构

### 2.1 电源树

```
DC 5V ──► PMIC(RK860) ─┬─► VDD_CPU (0.9V, 动态调压)
                       ├─► VDD_NPU (0.9V)
                       ├─► VDD_GPU (0.9V)
                       ├─► VCC_3V3 (3.3V)
                       ├─► VCC_1V8 (1.8V)
                       └─► VDD_LOG (0.9V)
```

### 2.2 关键电源

| 电源       | 电压   | 电流   | 用途           |
| ---------- | ------ | ------ | -------------- |
| VCC_SYS    | 5V     | 4A     | 系统输入       |
| VDD_CPU    | 0.9V   | 动态   | CPU 核心       |
| VDD_NPU    | 0.9V   | 动态   | NPU 核心       |
| VCC_3V3    | 3.3V   | 2A     | GPIO/外设      |
| VCC_1V8    | 1.8V   | 1A     | 部分 GPIO      |

## 3. 时钟架构

### 3.1 时钟源

| 时钟       | 频率      | 用途               |
| ---------- | --------- | ------------------ |
| HXTAL      | 24MHz     | 主外部晶振         |
| LXTAL      | 32.768kHz | RTC                |
| PLL        | 多路      | CPU/GPU/NPU/DDR    |

### 3.2 关键时钟

| 时钟域     | 频率       | 说明           |
| ---------- | ---------- | -------------- |
| CPU A72    | 2.2GHz     | big cluster    |
| CPU A53    | 1.8GHz     | LITTLE cluster |
| GPU        | 800MHz     | Mali-G52       |
| NPU        | 1.0GHz     | 6TOPS          |
| DDR        | 2112MHz    | LPDDR4X        |
| CSI DPHY   | 1.5Gbps    | 摄像头          |

## 4. 电源域

### 4.1 DVFS（动态电压频率调节）

| 域         | 调节点                     |
| ---------- | -------------------------- |
| CPU A72    | 408MHz~2.2GHz（多档）     |
| CPU A53    | 408MHz~1.8GHz             |
| GPU        | 200MHz~800MHz             |
| NPU        | 300MHz~1.0GHz             |

### 4.2 低功耗

- 系统待机：Suspend to RAM
- 外设独立使能控制
- NPU 空闲时降频
