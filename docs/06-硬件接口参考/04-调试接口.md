## 1. 概述

本文档介绍鲁班猫3 提供的调试接口与使用方法。

## 2. 串口调试

### 2.1 接口

- UART2（Type-C USB 转串口，板载 CH340）
- 波特率：1500000（U-Boot/内核默认）

### 2.2 连接

```
Type-C 数据线连接 PC → CH340 → UART2
```

### 2.3 工具

```bash
# Linux
minicom -D /dev/ttyUSB0 -b 1500000

# Windows
使用 MobaXterm / PuTTY，波特率 1500000
```

## 3. JTAG 调试

- 通过 40Pin 引出（需配置 pinctrl）
- 用于 U-Boot/内核底层调试
- 本项目一般不使用

## 4. 网络调试

### 4.1 TFTP 内核调试

```bash
# U-Boot 中设置
setenv bootcmd 'tftp 0x40600000 Image; tftp 0x44000000 rk3576-lbc3.dtb; booti 0x40600000 - 0x44000000'
setenv serverip 192.168.1.100
setenv ipaddr 192.168.1.50
saveenv
```

### 4.2 NFS 根文件系统

```
root=/dev/nfs nfsroot=192.168.1.100:/nfsroot ip=192.168.1.50
```

## 5. USB 调试

### 5.1 ADB

```bash
# Buildroot 启用 adb
adb connect <board_ip>
adb shell
```

### 5.2 USB 烧录

- 按 RECOVERY 键上电进入 Loader 模式
- 使用 upgrade_tool / RKDevTool 烧录
