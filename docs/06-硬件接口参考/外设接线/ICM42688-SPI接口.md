## 1. 概述

ICM42688 六轴 IMU（陀螺仪+加速度计），通过 SPI 接入 RK3576，用于电子防抖。

## 2. 接口规格

| 项目       | 规格              |
| ---------- | ----------------- |
| 总线       | SPI               |
| 模式       | CPOL=1, CPHA=1    |
| 最大频率   | 24MHz             |
| 电压       | 3.3V              |
| 陀螺仪范围 | ±2000 dps         |
| 加速度范围 | ±16g              |
| 采样率     | 最高 32kHz        |

## 3. 引脚定义

| ICM42688 Pin | 信号   | RK3576     | 40Pin 物理引脚 |
| ------------ | ------ | ---------- | -------------- |
| VDD          | 3.3V   | 3.3V       | 1              |
| GND          | GND    | GND        | 20             |
| CSB          | CS     | SPI0_CS0   | 24             |
| SCLK         | SCLK   | SPI0_SCLK  | 23             |
| SDI          | MOSI   | SPI0_MOSI  | 19             |
| SDO          | MISO   | SPI0_MISO  | 21             |
| INT1         | IRQ    | GPIO2_A0   | 22             |

## 4. SPI 时序

- CPOL=1（空闲高电平）
- CPHA=1（第二边沿采样）
- 读操作：地址 | 0x80
- 写操作：地址 & 0x7F

## 5. 寄存器

| 寄存器 | 地址 | 说明           |
| ------ | ---- | -------------- |
| WHO_AM_I | 0x75 | 设备 ID (0x47) |
| PWR_MGMT | 0x4C | 电源管理       |
| GYRO_CONFIG | 0x4F | 陀螺仪配置  |
| ACCEL_CONFIG | 0x50 | 加速度配置 |
| GYRO_DATA | 0x25 | 陀螺仪数据  |
| ACCEL_DATA | 0x1F | 加速度数据  |
