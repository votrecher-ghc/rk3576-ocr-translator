## 1. 概述

ICM42688 六轴 IMU（陀螺仪+加速度计），通过 SPI 接入 RK3576，用于电子防抖。

截至 2026-07-16，总线候选均为 SPI0 CS0，但早期文档的 IRQ 为 `GPIO2_A0` / 40Pin 22，当前 `icm42688-spi.dtso` 改为 `GPIO0_PB2`。SPI pinctrl、IRQ 物理脚和电源域尚未完成目标板核对，不能把下表视为已验证接线。

## 2. 接口规格

| 项目       | 规格              |
| ---------- | ----------------- |
| 总线       | SPI               |
| 模式       | CPOL=1, CPHA=1    |
| 最大频率   | 24MHz             |
| 当前 overlay 供电候选 | VDD 3.3V / VDDIO 1.8V |
| 陀螺仪范围 | ±2000 dps         |
| 当前加速度配置 | ±4g（8192 LSB/g） |
| 当前采样率配置 | 加速度和陀螺仪均为 1kHz |

## 3. 引脚候选

| ICM42688 Pin | 信号 | 早期接线候选 | 当前 overlay 候选 |
| ------------ | ---- | ------------ | ------------------ |
| VDD          | 电源 | 3.3V / 40Pin 1 | `vcc_3v3_s3` |
| VDDIO        | I/O 电源 | 早期表未区分 | `vcc_1v8_s3` |
| GND          | 地   | GND / 40Pin 20 | GND |
| CSB          | CS   | SPI0_CS0 / 40Pin 24 | `spi0` CS0，物理脚待核对 |
| SCLK         | 时钟 | SPI0_SCLK / 40Pin 23 | `spi0`，物理脚待核对 |
| SDI          | MOSI | SPI0_MOSI / 40Pin 19 | `spi0`，物理脚待核对 |
| SDO          | MISO | SPI0_MISO / 40Pin 21 | `spi0`，物理脚待核对 |
| INT1         | IRQ  | `GPIO2_A0` / 40Pin 22 | `GPIO0_PB2`，下降沿，物理脚待核对 |

特别注意当前 overlay 将 VDDIO 指向 1.8V。必须确认所用 ICM42688 模块是否将 VDDIO 单独引出、模块上是否带电平转换，以及 base DTS 的供电节点和实际板卡一致。

## 4. SPI 时序

- CPOL=1（空闲高电平）
- CPHA=1（第二边沿采样）
- 读操作：地址 | 0x80
- 写操作：地址 & 0x7F
- 当前 overlay 的 `spi-max-frequency` 为 24MHz；首次板端验证宜从较低频率开始，再根据波形和读写稳定性提升

## 5. 寄存器

| 寄存器 | 地址 | 说明           |
| ------ | ---- | -------------- |
| WHO_AM_I | 0x75 | 设备 ID (0x47) |
| PWR_MGMT0 | 0x4E | 电源管理       |
| GYRO_CONFIG0 | 0x4F | 陀螺仪配置  |
| ACCEL_CONFIG0 | 0x50 | 加速度配置 |
| GYRO_DATA | 0x25 | 陀螺仪数据  |
| ACCEL_DATA | 0x1F | 加速度数据  |
