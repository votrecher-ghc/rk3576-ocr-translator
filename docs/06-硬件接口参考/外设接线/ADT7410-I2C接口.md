## 1. 概述

ADT7410 高精度数字温度传感器，通过 I2C 接入 RK3576，与 AP3216C 共用 I2C2 总线。

## 2. 接口规格

| 项目       | 规格              |
| ---------- | ----------------- |
| 总线       | I2C               |
| I2C 地址   | 0x48（7-bit）     |
| 电压       | 3.3V              |
| 精度       | ±0.5°C            |
| 分辨率     | 16-bit (0.0078°C) |
| 量程       | -55°C ~ +150°C    |

## 3. 引脚定义

| ADT7410 Pin | 信号 | RK3576       | 40Pin 物理引脚 |
| ----------- | ---- | ------------ | -------------- |
| VDD         | 3.3V | 3.3V         | 1              |
| GND         | GND  | GND          | 25             |
| SCL         | I2C  | I2C2_SCL     | 5              |
| SDA         | I2C  | I2C2_SDA     | 3              |
| CT/INT      | -    | 未连接       | -              |
| A0/A1       | GND  | 地址选择     | -              |

## 4. 寄存器

| 寄存器 | 地址 | 说明           |
| ------ | ---- | -------------- |
| CONFIG | 0x03 | 配置寄存器     |
| TEMP   | 0x00 | 温度值（16bit）|
| T_HIGH | 0x04 | 高温阈值       |
| T_LOW  | 0x05 | 低温阈值       |
| T_CRIT | 0x06 | 临界阈值       |

### 温度计算

```
temp_mC = (raw & 0x7FFF) * 1000 / 128  // 正数
temp_mC = (raw | 0xFFFF8000) * 1000 / 128  // 负数（符号扩展）
```

## 5. 电气特性

- I2C 电平：3.3V
- 与 AP3216C 共用 I2C2 总线（地址不同：0x48 vs 0x1E）
- 转换时间：240ms（16-bit 模式）
