## 1. 概述

ADT7410 高精度数字温度传感器，通过 I2C 接入 RK3576。

截至 2026-07-16，早期接线候选是与 AP3216C 共用 I2C2 / 40Pin 3、5；当前 `adt7410.dtso` 和 `ap3216c.dtso` 则共同指向 `i2c4`。两组定义尚未完成原理图与 base DTS 联合核对。

## 2. 接口规格

| 项目       | 规格              |
| ---------- | ----------------- |
| 总线       | I2C               |
| I2C 地址   | 0x48（7-bit）     |
| 电压       | 3.3V              |
| 精度       | ±0.5°C            |
| 分辨率     | 16-bit (0.0078°C) |
| 量程       | -55°C ~ +150°C    |

## 3. 引脚候选

| ADT7410 Pin | 信号 | 早期接线候选 | 当前 overlay 候选 |
| ----------- | ---- | ------------ | ------------------ |
| VDD         | 电源 | 3.3V / 40Pin 1 | `vcc_3v3_s3` |
| GND         | 地   | GND / 40Pin 25 | GND |
| SCL         | I2C  | I2C2_SCL / 40Pin 5 | `i2c4` 的 SCL，物理脚待核对 |
| SDA         | I2C  | I2C2_SDA / 40Pin 3 | `i2c4` 的 SDA，物理脚待核对 |
| CT/INT      | 告警 | 未连接 | 当前 overlay 未配置 |
| A0/A1       | 地址选择 | GND，地址 0x48 | 需与模块焊盘/原理图一致 |

## 4. 寄存器

| 寄存器 | 地址 | 说明 |
| ------ | ---- | ---- |
| TEMP_MSB | 0x00 | 温度高字节 |
| TEMP_LSB | 0x01 | 温度低字节 |
| STATUS | 0x02 | 状态寄存器 |
| CONFIG | 0x03 | 配置寄存器 |
| T_HIGH_MSB | 0x04 | 高温阈值高字节 |
| T_HIGH_LSB | 0x05 | 高温阈值低字节 |
| T_LOW_MSB | 0x06 | 低温阈值高字节 |
| T_LOW_LSB | 0x07 | 低温阈值低字节 |
| T_CRIT_MSB | 0x08 | 临界阈值高字节 |
| T_CRIT_LSB | 0x09 | 临界阈值低字节 |
| T_HYST | 0x0A | 阈值滞后 |
| ID | 0x0B | 器件 ID |

### 温度计算

```text
raw = (int16_t)((msb << 8) | lsb)
temp_mC = raw * 125 / 16
```

16-bit 模式下 `raw` 是有符号二进制补码，比例为 `7.8125 m°C/LSB`，即 `125/16 m°C/LSB`。应先完成 16-bit 符号扩展，再做乘除；不要用 `raw & 0x7FFF` 处理正数，否则会掩盖错误的符号解释。

## 5. 电气特性

- 供电候选为 3.3V；I2C 实际 I/O 电压域需查原理图
- 早期候选与 AP3216C 共用 I2C2，当前 overlay 候选改为共同使用 `i2c4`（地址不同：0x48 与 0x1E）
- I2C 上拉、电压域和物理引脚必须按原理图/base DTS 核对
- 转换时间：240ms（16-bit 模式）
