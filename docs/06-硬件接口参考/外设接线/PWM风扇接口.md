## 1. 概述

PWM 风扇用于 RK3576 主动散热，通过 PWM9 接口调速。

## 2. 接口规格

| 项目       | 规格              |
| ---------- | ----------------- |
| 控制       | PWM               |
| PWM 通道   | PWM9              |
| 频率       | 20kHz             |
| 电压       | 5V                |
| 占空比范围 | 0%~100%           |

## 3. 引脚定义

| 风扇 Pin | 信号 | RK3576       | 40Pin 物理引脚 |
| -------- | ---- | ------------ | -------------- |
| VCC      | 5V   | 5V           | 2              |
| GND      | GND  | GND          | 34             |
| PWM      | PWM  | PWM9 (GPIO2_B4) | 32          |
| TACH     | -    | 未连接（可选）| -            |

## 4. PWM 参数

```bash
# PWM 周期 50000ns = 20kHz
period = 50000
duty_cycle = 0~50000 (对应 0%~100%)
```

## 5. 风扇选型

- 5V PWM 控制风扇
- 推荐 4010/4020 规格
- 支持转速反馈（TACH）可选
