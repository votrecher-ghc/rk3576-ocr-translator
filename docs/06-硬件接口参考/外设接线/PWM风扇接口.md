## 1. 概述

PWM 风扇用于 RK3576 主动散热。早期硬件表指定 PWM9，而当前示例 overlay 目标为
PWM11；这是必须在原理图与 vendor base DTS 上闭环的差异，未核对前不能直接烧录。

## 2. 接口规格

| 项目       | 规格              |
| ---------- | ----------------- |
| 控制       | PWM               |
| PWM 通道   | 待核对（早期设计 PWM9；当前示例 PWM11） |
| 频率       | 25kHz             |
| 电压       | 5V                |
| 占空比范围 | 0%~100%           |

## 3. 引脚定义

| 风扇 Pin | 信号 | RK3576       | 40Pin 物理引脚 |
| -------- | ---- | ------------ | -------------- |
| VCC      | 5V   | 5V           | 2              |
| GND      | GND  | GND          | 34             |
| PWM      | PWM  | 待核对（早期设计为 PWM9/GPIO2_B4） | 32（待核对） |
| TACH     | -    | 未连接（可选）| -            |

## 4. PWM 参数

```bash
# PWM 周期 40000ns = 25kHz
period = 40000
duty_cycle = 0~40000 (对应 0%~100%)
```

应用按 overlay 的 `ocr,fan-pwm` 标记动态查找 `pwmchip`，不依赖控制器编号映射到
`pwmchipN` 的偶然顺序。必须确认风扇输入极性和最低可靠启转占空比。

## 5. 风扇选型

- 5V PWM 控制风扇
- 推荐 4010/4020 规格
- 支持转速反馈（TACH）可选
