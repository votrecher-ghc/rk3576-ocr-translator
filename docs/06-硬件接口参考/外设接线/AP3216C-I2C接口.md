## 1. 概述

AP3216C 集成环境光传感器（ALS）、接近传感器（PS），通过 I2C 接入 RK3576。

## 2. 接口规格

| 项目       | 规格              |
| ---------- | ----------------- |
| 总线       | I2C               |
| I2C 地址   | 0x1E（7-bit）     |
| 电压       | 3.3V              |
| 采样率     | 最高 10Hz         |
| ALS 量程   | 0~65535 lux       |

## 3. 引脚定义

| AP3216C Pin | 信号 | RK3576       | 40Pin 物理引脚 |
| ----------- | ---- | ------------ | -------------- |
| VCC         | 3.3V | 3.3V         | 1              |
| GND         | GND  | GND          | 25             |
| SCL         | I2C  | I2C2_SCL     | 5              |
| SDA         | I2C  | I2C2_SDA     | 3              |
| INT         | IRQ  | GPIO2_C0     | 36             |

## 4. 寄存器

| 寄存器 | 地址 | 说明               |
| ------ | ---- | ------------------ |
| SYS    | 0x00 | 系统配置/复位      |
| INT    | 0x01 | 中断状态           |
| ALS_L  | 0x0C | ALS 数据低字节     |
| ALS_H  | 0x0D | ALS 数据高字节     |
| PS_L   | 0x0E | PS 数据低字节      |
| PS_H   | 0x0F | PS 数据高字节      |

## 5. 电气特性

- I2C 电平：3.3V
- 需外接 4.7kΩ 上拉电阻
- 中断输出：开漏，低有效
