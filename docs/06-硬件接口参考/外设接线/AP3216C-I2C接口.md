## 1. 概述

AP3216C 集成环境光传感器（ALS）、接近传感器（PS），通过 I2C 接入 RK3576。

截至 2026-07-16，本文的物理接线仍是候选方案：早期文档使用 I2C2 / 40Pin 3、5 和 `GPIO2_C0` / 40Pin 36；当前 `ap3216c.dtso` 使用 `i2c4` 和 `GPIO0_PA1`。两者并不一致，必须按目标板原理图、40Pin 定义及 base DTS/pinctrl 核对后再接线。

## 2. 接口规格

| 项目       | 规格              |
| ---------- | ----------------- |
| 总线       | I2C               |
| I2C 地址   | 0x1E（7-bit）     |
| 电压       | 3.3V              |
| 采样率     | 最高 10Hz         |
| 当前驱动 ALS 配置 | 默认档，0~20661 lux |
| 当前驱动 ALS 比例 | 0.35 lux/LSB |
| PS 输出     | 10-bit 相对计数，无物理单位比例 |

## 3. 引脚候选

| AP3216C Pin | 信号 | 早期接线候选 | 当前 overlay 候选 |
| ----------- | ---- | ------------ | ------------------ |
| VCC         | 电源 | 3.3V / 40Pin 1 | `vcc_3v3_s3` |
| GND         | 地   | GND / 40Pin 25 | GND |
| SCL         | I2C  | I2C2_SCL / 40Pin 5 | `i2c4` 的 SCL，物理脚待核对 |
| SDA         | I2C  | I2C2_SDA / 40Pin 3 | `i2c4` 的 SDA，物理脚待核对 |
| INT         | IRQ  | `GPIO2_C0` / 40Pin 36 | `GPIO0_PA1`，下降沿，物理脚待核对 |

当前 overlay 没有单独声明 I2C/IRQ pinctrl，控制器节点存在并不代表对应信号已复用到上述 40Pin。

## 4. 寄存器

| 寄存器 | 地址 | 说明               |
| ------ | ---- | ------------------ |
| SYS    | 0x00 | 系统配置/复位      |
| INT    | 0x01 | 中断状态           |
| ALS_L  | 0x0C | ALS 数据低字节     |
| ALS_H  | 0x0D | ALS 数据高字节     |
| PS_L   | 0x0E | PS 数据低字节      |
| PS_H   | 0x0F | PS 数据高字节      |

当前驱动按 `PS_H[5:0] << 4 | PS_L[3:0]` 组合 10-bit PS 数据；任一数据字节的 IR overflow 位有效时，读数应视为无效。

## 5. 电气特性

- 供电候选为 3.3V；I2C 实际 I/O 电压域必须查原理图
- 是否已有板载上拉、上拉到哪个电源域及阻值必须实测/查图，4.7kΩ 仅是常见候选
- 中断输出：开漏，低有效
- 上电前确认模块电源、SDA/SCL 和 INT 不会接入不兼容电压
