## 1. 概述

用户按键用于触发拍照翻译，通过 GPIO 接入 RK3576。

## 2. 接口规格

| 项目       | 规格              |
| ---------- | ----------------- |
| 接口       | GPIO              |
| 电平       | 3.3V              |
| 触发方式   | 低电平有效        |
| 去抖       | 硬件 RC + 软件    |

## 3. 引脚定义

| 按键 Pin | 信号 | RK3576       | 40Pin 物理引脚 |
| -------- | ---- | ------------ | -------------- |
| 一端     | KEY  | GPIO1_A4     | 7              |
| 另一端   | GND  | GND          | 9              |

## 4. 硬件设计

```
3.3V ──[10kΩ上拉]──┬──► GPIO1_A4
                   │
                   └── 按键 ── GND
```

- 上拉电阻：10kΩ（内部上拉可用）
- 硬件去抖：0.1μF 电容并联
- 软件去抖：debounce-interval = 10ms

### 按键事件

| 动作     | 事件           |
| -------- | -------------- |
| 短按     | 拍照翻译       |
| 长按(>2s)| 模式切换       |
