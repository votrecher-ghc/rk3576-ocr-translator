## 1. 概述

用户按键用于触发拍照翻译，通过 Linux input 事件接入应用。当前驱动/应用约定的按键码为 `KEY_CAMERA`（0xd4）。

截至 2026-07-16，早期接线候选是 `GPIO1_A4` / 40Pin 7，另有文档曾记录 `GPIO0_A6`；当前 `gpio-keys.dtso` 使用 `GPIO0_PC0`。这些 GPIO 候选不一致，必须按目标板原理图、40Pin 表及 base DTS/pinctrl 核对。

## 2. 接口规格

| 项目       | 规格              |
| ---------- | ----------------- |
| 接口       | GPIO              |
| 电平       | 以目标 GPIO 电源域为准 |
| 触发方式   | 低电平有效        |
| input 事件 | `EV_KEY / KEY_CAMERA` |
| 当前 overlay 去抖 | 20ms |

## 3. 引脚候选

| 按键 Pin | 信号 | 早期接线候选 | 当前 overlay 候选 |
| -------- | ---- | ------------ | ------------------ |
| 一端     | KEY  | `GPIO1_A4` / 40Pin 7；另有 `GPIO0_A6` 记录 | `GPIO0_PC0`，物理脚待核对 |
| 另一端   | GND  | GND / 40Pin 9 | GND |

## 4. 硬件设计

```
I/O 电源 ──[上拉]──┬──► 待核对的 GPIO
                   │
                   └── 按键 ── GND
```

- 上拉电源必须匹配该 GPIO 的 I/O 电压域；10kΩ 仅为候选值
- 是否增加 0.1μF RC 去抖需结合边沿速度、漏电和实测波形确认
- 当前 overlay：`debounce-interval = 20ms`
- 当前内核驱动在稳定状态变化时上报 `KEY_CAMERA` 按下/释放；应用忽略自动重复事件

### 按键事件

| 动作 | 当前行为 |
| ---- | -------- |
| 按下/释放 | 上报 `EV_KEY / KEY_CAMERA`，应用映射为拍照按键事件 |
| 长按 | **未实现独立长按计时或模式切换**；自动重复事件会被应用忽略 |
