## 1. 芯片与硬件术语

| 术语        | 全称                                          | 说明                                                                 |
| ----------- | --------------------------------------------- | -------------------------------------------------------------------- |
| RK3576      | Rockchip RK3576                               | 瑞芯微推出的高性能 SoC，集成 A72+A53+NPU，面向边缘 AI               |
| SoC         | System on Chip                                | 片上系统，将 CPU/GPU/NPU/ISP 等集成于单一芯片                       |
| big.LITTLE  | big.LITTLE Architecture                       | ARM 大小核架构，大核高性能、小核低功耗                               |
| NPU         | Neural Processing Unit                        | 神经网络处理器，RK3576 内置 6TOPS@INT8 算力                          |
| ISP         | Image Signal Processor                        | 图像信号处理器，负责摄像头原始数据（RAW）的降噪、白平衡等处理        |
| CSI         | Camera Serial Interface                       | MIPI-CSI，摄像头串行接口，用于连接 IMX415                            |
| eMMC        | Embedded Multi Media Card                    | 嵌入式多媒体卡，板载 32GB 存储                                       |
| LPDDR4X     | Low Power DDR4X                               | 低功耗双倍速率内存，板载 4GB                                        |
| CMA         | Contiguous Memory Allocator                   | 连续内存分配器，内核用于分配大块物理连续内存（DMA 缓冲）             |

## 2. 显示与图形术语

| 术语        | 全称                                          | 说明                                                                 |
| ----------- | --------------------------------------------- | -------------------------------------------------------------------- |
| DRM         | Direct Rendering Manager                      | Linux 直接渲染管理器，内核显示子系统，管理 GPU/显示控制器             |
| KMS         | Kernel Mode Setting                           | 内核模式设置，DRM 的一部分，负责显示输出、图层、CRTC 配置            |
| CRTC        | CRT Controller                                | 阴极射线管控制器（历史名称），实际指显示扫描输出控制器               |
| Plane       | DRM Plane                                     | DRM 图层，一个 CRTC 可叠加多个 Plane（如视频层+OSD层）              |
| Connector   | DRM Connector                                 | DRM 连接器，对应物理输出（HDMI/DSI/RGB）                             |
| Encoder     | DRM Encoder                                   | DRM 编码器，将 CRTC 输出转换为 Connector 所需信号                    |
| FB          | DRM Framebuffer                              | DRM 帧缓冲，实际是 DMA-BUF 的封装，供 Plane 显示                     |
| VSYNC       | Vertical Synchronization                      | 垂直同步信号，用于帧同步，避免画面撕裂                               |
| RGA         | Raster Graphic Acceleration Unit              | 瑞芯微 2D 光栅图形加速器，支持缩放/旋转/格式转换/拼接                 |
| OSD         | On Screen Display                             | 屏幕显示叠加，用于在预览画面上叠加翻译文本                           |

## 3. 视频与摄像头术语

| 术语        | 全称                                          | 说明                                                                 |
| ----------- | --------------------------------------------- | -------------------------------------------------------------------- |
| V4L2        | Video4Linux2                                  | Linux 视频采集框架，提供摄像头/视频设备的统一接口                    |
| DMA-BUF     | DMA Buffer Sharing                            | DMA 缓冲共享框架，允许不同驱动/进程共享同一块物理内存，实现零拷贝    |
| DMABUF      | DMA Buffer                                    | DMA-BUF 框架中的缓冲对象，可跨子系统传递                             |
| RAW         | RAW Image Format                              | 传感器原始数据格式（如 RAW10/RAW12），未经 ISP 处理                  |
| YUV         | YUV Color Space                               | 亮度色度分离色彩空间，视频常用 NV12/NV16 等                          |
| NV12        | YUV 4:2:0 Semi-Planar                        | Y 分量连续存储，UV 交织存储，V4L2/DRM 常用格式                       |
| MMAP        | Memory Mapped                                 | V4L2 缓冲获取方式之一，将内核缓冲映射到用户空间                      |
| DMABUF导入  | V4L2_MEMORY_DMABUF                           | V4L2 缓冲类型，使用外部 DMA-BUF 作为输出缓冲                         |
| Exposure    | 曝光时间                                      | 摄像头传感器积分时间，影响画面明暗                                   |
| Gain        | 增益                                         | 摄像头模拟/数字增益                                                  |

## 4. 内核子系统术语

| 术语        | 全称                                          | 说明                                                                 |
| ----------- | --------------------------------------------- | -------------------------------------------------------------------- |
| DTS         | Device Tree Source                            | 设备树源文件，描述硬件信息，内核启动时解析                           |
| DTB         | Device Tree Blob                              | 设备树二进制，DTS 编译产物                                           |
| DTO         | Device Tree Overlay                           | 设备树覆盖层，运行时动态修改设备树                                   |
| pinctrl     | Pin Control                                   | 引脚控制子系统，管理 GPIO 复用、上下拉、驱动强度                     |
| GPIO        | General Purpose Input/Output                  | 通用输入输出                                                         |
| I2C         | Inter-Integrated Circuit                      | 两线串行总线，连接 AP3216C、ADT7410                                  |
| SPI         | Serial Peripheral Interface                   | 串行外设接口，连接 ICM42688                                          |
| PWM         | Pulse Width Modulation                        | 脉宽调制，用于风扇调速                                               |
| IIO         | Industrial I/O                                | 工业输入输出子系统，统一管理 ADC/DAC/加速度计/温度等传感器           |
| Input       | Input Subsystem                               | 输入子系统，管理按键、鼠标、键盘等输入设备                           |
| IRQ         | Interrupt Request                             | 中断请求                                                             |
| DTBO        | Device Tree Blob Overlay                      | DTO 编译后的二进制文件                                               |

## 5. AI 与推理术语

| 术语        | 全称                                          | 说明                                                                 |
| ----------- | --------------------------------------------- | -------------------------------------------------------------------- |
| RKNN        | Rockchip Neural Network                       | 瑞芯微神经网络模型格式，NPU 可直接执行                               |
| NPU         | Neural Processing Unit                        | 神经网络处理器                                                       |
| OCR         | Optical Character Recognition                 | 光学字符识别，将图像中文字转为文本                                   |
| INT8        | 8-bit Integer                                 | 8 位整数量化，NPU 推理常用精度                                       |
| Quantization| 模型量化                                      | 将浮点模型转为低精度（INT8）以加速推理                               |
| Inference   | 推理                                          | 模型前向计算过程                                                     |
| Detection   | 检测                                          | 文字检测，定位图像中文字区域                                         |
| Recognition | 识别                                          | 文字识别，将文字区域转为文本                                         |

## 6. 构建与开发术语

| 术语        | 全称                                          | 说明                                                                 |
| ----------- | --------------------------------------------- | -------------------------------------------------------------------- |
| Buildroot   | Buildroot                                     | Linux 系统构建框架，自动化生成交叉编译工具链、内核、根文件系统       |
| CMake       | Cross-platform Make                           | 跨平台构建工具，用于应用层编译                                       |
| U-Boot      | Universal Boot Loader                         | 通用引导加载程序                                                     |
| Cross Toolchain | 交叉编译工具链                             | 在 x86 主机上编译 ARM 目标程序的 GCC 工具链                          |
| defconfig   | Default Configuration                         | 内核/U-Boot 默认配置文件                                             |
| rootfs      | Root Filesystem                               | 根文件系统                                                           |
| OTA         | Over The Air                                  | 空中升级                                                             |
| TFTP        | Trivial File Transfer Protocol                | 简单文件传输协议，用于内核调试下载                                   |
| NFS         | Network File System                           | 网络文件系统，用于挂载网络根文件系统调试                             |

## 7. 其他术语

| 术语        | 全称                                          | 说明                                                                 |
| ----------- | --------------------------------------------- | -------------------------------------------------------------------- |
| EIS         | Electronic Image Stabilization                | 电子防抖，基于陀螺仪数据对图像进行反向补偿                           |
| IMU         | Inertial Measurement Unit                     | 惯性测量单元，含陀螺仪和加速度计                                     |
| API         | Application Programming Interface             | 应用程序编程接口                                                     |
| FIFO        | First In First Out                            | 先进先出队列                                                         |
| DMA         | Direct Memory Access                          | 直接内存访问，外设与内存间数据传输不经过 CPU                         |
| MMU         | Memory Management Unit                        | 内存管理单元，虚拟地址到物理地址映射                                 |
