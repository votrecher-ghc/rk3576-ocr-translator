## 1. 文档导读

本文档体系涵盖基于鲁班猫3 RK3576 开发板的端侧 OCR 实时翻译系统的全部技术文档，包括总览、架构设计、模块设计、驱动开发、API 接口、编译构建、硬件接口、测试、部署运维、开发流程和附录共 11 个章节。

### 1.1 文档约定

- 所有文档采用 Markdown 格式
- 代码示例使用 C 语言或 DTS 语法，特殊说明除外
- 文件路径使用正斜杠 `/` 分隔
- 每个文档首部包含版本信息表，记录版本号、日期、作者、变更说明

### 1.2 版本规则

- 主版本号（X.0）：架构性变更、大范围重构
- 次版本号（1.X）：新增功能、补充章节
- 修订号（1.0.X）：修正错误、优化表述
