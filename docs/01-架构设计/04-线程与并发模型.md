## 1. 线程总览

系统共 10 个线程，分布在 A72 大核与 A53 小核上：

```
┌──────── A72 (CPU0-3) ────────┐  ┌──────── A53 (CPU4-7) ────────┐
│  Main 主控线程                │  │  V4L2 Capture 采集线程        │
│  OCR Inference 推理线程       │  │  DRM Display 显示线程         │
│  Translate 翻译线程           │  │  RGA Process 处理线程         │
│                               │  │  IMU Sensor 传感器线程        │
│                               │  │  Light Sensor 环境光线程      │
│                               │  │  Thermal 温度线程             │
│                               │  │  Input 按键线程               │
└───────────────────────────────┘  └───────────────────────────────┘
```

## 2. 各线程职责

| 线程名          | CPU亲和 | 优先级 | 职责                              | 关键API                |
| --------------- | ------- | ------ | --------------------------------- | ---------------------- |
| Main            | A72     | 普通   | 模式管理、生命周期、事件分发      | pthread主线程          |
| V4L2 Capture    | A53     | SCHED_FIFO 80 | 摄像头帧采集，DQBUF/QBUF         | ioctl VIDIOC_DQBUF     |
| DRM Display     | A53     | SCHED_FIFO 80 | VSync同步显示，PageFlip          | drmModePageFlip        |
| RGA Process     | A53     | SCHED_FIFO 70 | 图像缩放/格式转换                 | rga_process            |
| OCR Inference   | A72     | SCHED_FIFO 90 | RKNN模型推理                     | rknn_run               |
| Translate       | A72     | 普通   | 翻译引擎执行                      | translate_run          |
| IMU Sensor      | A53     | SCHED_FIFO 60 | ICM42688数据采集，EIS计算        | iio buffer read        |
| Light Sensor    | A53     | 普通   | AP3216C环境光采集，背光调节       | iio sysfs read         |
| Thermal         | A53     | 普通   | ADT7410温度监测，风扇调速         | iio sysfs + pwm sysfs  |
| Input           | A53     | 普通   | 按键事件读取与分发                | evdev read             |

## 3. 同步机制

### 3.1 同步方式总览

| 同步对象       | 机制             | 用途                           |
| -------------- | ---------------- | ------------------------------ |
| DMA-BUF 缓冲   | 信号量 + 原子引用 | 缓冲池空闲/占用管理            |
| 帧队列         | 互斥锁 + 条件变量 | V4L2→RGA→DRM 帧传递            |
| OCR 结果队列   | 互斥锁 + 条件变量 | OCR结果异步传递给翻译/显示     |
| VSync 事件     | drmHandleEvent  | 显示同步                       |
| 模式状态       | 原子变量         | 实时/拍照模式切换              |
| 配置参数       | 读写锁           | 运行时配置读写                 |

### 3.2 关键同步点

#### V4L2 → RGA → DRM 帧传递
```
V4L2线程: DQBUF → 信号量通知 → 放入就绪队列
RGA线程:  从就绪队列取帧 → RGA处理 → 放入显示队列
DRM线程:  从显示队列取帧 → PageFlip → VSync等待 → 归还缓冲
```

#### OCR 异步推理
```
RGA线程: 预处理完成 → 投入OCR请求队列
OCR线程: 取请求 → rknn_run → 投入结果队列
翻译线程: 取OCR结果 → 翻译 → 投入OSD渲染
```

## 4. 线程间通信

### 4.1 通信方式

| 方式           | 场景                         | 实现                     |
| -------------- | ---------------------------- | ------------------------ |
| DMA-BUF fd     | 图像数据传递                 | 共享 fd（同一进程内）    |
| 帧队列         | 帧的异步传递                 | 环形队列 + 条件变量      |
| 回调函数       | 事件通知                     | 函数指针                 |
| 共享原子变量   | 状态/模式                    | stdatomic                |
| 配置结构体     | 运行时参数                   | 读写锁保护               |

### 4.2 帧队列设计

```c
// 环形帧队列
typedef struct {
    dma_buf_t *bufs[QUEUE_SIZE];
    int head, tail, count;
    pthread_mutex_t lock;
    pthread_cond_t not_empty;
    pthread_cond_t not_full;
} frame_queue_t;
```

## 5. CPU 亲和与调度

### 5.1 CPU 亲和设置

```c
// A72 大核 (CPU0-3)
cpu_set_t a72_set;
CPU_ZERO(&a72_set);
CPU_SET(0, &a72_set); CPU_SET(1, &a72_set);
CPU_SET(2, &a72_set); CPU_SET(3, &a72_set);
pthread_setaffinity_np(thread, sizeof(a72_set), &a72_set);

// A53 小核 (CPU4-7)
cpu_set_t a53_set;
CPU_ZERO(&a53_set);
CPU_SET(4, &a53_set); CPU_SET(5, &a53_set);
CPU_SET(6, &a53_set); CPU_SET(7, &a53_set);
pthread_setaffinity_np(thread, sizeof(a53_set), &a53_set);
```

### 5.2 调度策略

| 线程类型       | 调度策略         | 优先级 |
| -------------- | ---------------- | ------ |
| 实时管线线程   | SCHED_FIFO       | 70-90  |
| AI/翻译线程    | SCHED_FIFO/OTHER | 90/普通|
| 传感器线程     | SCHED_OTHER      | 普通   |

### 5.3 死锁避免

- 严格遵循锁获取顺序：V4L2锁 → RGA锁 → DRM锁
- DMA-BUF 引用计数替代锁（避免长时间持锁）
- 翻译等耗时操作不持锁，通过队列异步
