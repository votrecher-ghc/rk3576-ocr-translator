## 1. 数据流概览

系统存在两条主要数据流和一条控制流：
- **实时翻译数据流**：V4L2 采集 → RGA 处理 → DRM 显示 + RKNN OCR → 翻译 → OSD 叠加
- **拍照数据流**：按键触发 → V4L2 采集 → RGA + RKNN OCR → 翻译 → 合成归档
- **传感器控制流**：环境光 → 屏幕亮度调节；IMU → 防抖补偿；温度 → 风扇调速

## 2. 实时翻译模式数据流

### 2.1 数据流图

```
┌─────────┐    ┌─────────┐    ┌──────────┐    ┌──────────┐    ┌─────────┐
│ IMX415  │───►│ CSI/ISP │───►│ V4L2     │───►│ RGA      │───►│ DRM     │
│ Sensor  │    │         │    │ Capture  │    │ Process  │    │ Display │
└─────────┘    └─────────┘    └──────────┘    └──────────┘    └─────────┘
                                   │              │               ▲
                                   │ DMA-BUF fd   │ DMA-BUF fd    │
                                   ▼              ▼               │
                              ┌──────────┐   ┌──────────┐        │
                              │ RGA      │──►│ RKNN     │        │
                              │ 预处理   │   │ OCR推理  │        │
                              └──────────┘   └──────────┘        │
                                                │                 │
                                                ▼                 │
                                          ┌──────────┐    ┌──────┴────┐
                                          │ 翻译引擎 │───►│ OSD渲染   │
                                          │Translate │    │ Plane1    │
                                          └──────────┘    └───────────┘
```

### 2.2 各环节说明

| 环节       | 输入           | 处理                       | 输出           | 数据格式     |
| ---------- | -------------- | -------------------------- | -------------- | ------------ |
| V4L2 采集  | CSI/ISP        | DMA-BUF 出帧               | DMA-BUF fd     | NV12         |
| RGA 显示路 | DMA-BUF fd     | 缩放到屏幕分辨率           | DMA-BUF fd     | NV12         |
| DRM 显示   | DMA-BUF fd     | 导入到 Framebuffer，显示   | 屏幕输出       | -            |
| RGA AI 路  | DMA-BUF fd     | 缩放到 OCR 输入尺寸        | DMA-BUF fd     | RGB888       |
| RKNN OCR   | RGB888 buffer  | 文字检测+识别              | 文本+坐标      | 文本         |
| 翻译引擎   | 文本           | 机器翻译                   | 译文           | 文本         |
| OSD 渲染   | 译文+坐标      | 文本渲染到缓冲             | DMA-BUF fd     | ARGB8888     |
| DRM OSD    | OSD DMA-BUF    | 叠加到 Plane1              | 屏幕叠加       | -            |

## 3. 拍照模式数据流

### 3.1 数据流图

```
按键事件
   │
   ▼
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 模式切换  │───►│ V4L2     │───►│ RGA      │───►│ RKNN     │
│ 拍照模式  │    │ 高清采集 │    │ 预处理   │    │ OCR推理  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                                                     │
                                                     ▼
                ┌──────────┐    ┌──────────┐    ┌──────────┐
                │ 归档存储  │◄───│ 结果合成 │◄───│ 翻译引擎 │
                │ JPG+TXT  │    │ 图文叠加 │    │ Translate│
                └──────────┘    └──────────┘    └──────────┘
                     │
                     ▼
                ┌──────────┐
                │ 恢复预览 │
                └──────────┘
```

### 3.2 与实时模式差异

| 项目       | 实时模式         | 拍照模式               |
| ---------- | ---------------- | ---------------------- |
| 触发方式   | 持续运行         | 按键触发               |
| 采集分辨率 | 1080p            | 4K（最高）             |
| OCR 精度   | 标准             | 高精度（可选大模型）   |
| 输出       | 屏幕叠加显示     | 归档文件（JPG+TXT）    |
| 延迟要求   | ≤300ms           | ≤2s（可接受）          |

## 4. 传感器控制流

### 4.1 环境光 → 屏幕亮度调节

```
AP3216C ──I2C──► IIO ──sysfs──► sensors线程
                                      │
                                      ├─ lux → 分段映射 → 目标亮度
                                      │
                                      └──► /sys/class/backlight/.../brightness
                                           │
                                           ▼
                                        屏幕背光
```

### 4.2 IMU → 电子防抖

```
ICM42688 ──SPI──► IIO ──buffer──► stab线程
                                      │
                                      ├─ 时间戳对齐
                                      ├─ 抖动量计算
                                      │
                                      └──► RGA 变换参数
                                           (crop offset)
                                           │
                                           ▼
                                        RGA 处理
```

### 4.3 温度 → 风扇调速

```
ADT7410 ──I2C──► IIO ──sysfs──► thermal线程
                                      │
                                      ├─ 查温度-转速表
                                      │
                                      └──► PWM duty cycle
                                           (sysfs)
                                           │
                                           ▼
                                        风扇
```

## 5. 数据格式流转

### 5.1 图像格式链

```
IMX415 RAW10 → ISP → NV12(1080p/4K)
                        │
                        ├─→ RGA → NV12(屏幕分辨率) → DRM Plane0
                        │
                        └─→ RGA → RGB888(OCR尺寸) → RKNN → 文本
                                                          │
                                                          └→ 翻译 → ARGB8888 → DRM Plane1
```

### 5.2 关键数据结构

| 数据         | 格式         | 载体       |
| ------------ | ------------ | ---------- |
| 采集帧       | NV12         | DMA-BUF fd |
| OCR 输入     | RGB888       | DMA-BUF fd |
| 显示帧       | NV12         | DRM FB     |
| OSD 叠加     | ARGB8888     | DMA-BUF fd |
| OCR 结果     | 文本+坐标    | 结构体     |
| IMU 数据     | 6轴浮点      | IIO buffer |
| 环境光数据   | lux 整数     | IIO sysfs  |
| 温度数据     | 毫摄氏度     | IIO sysfs  |
