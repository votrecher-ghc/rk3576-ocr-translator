## 1. 模块清单

系统共划分为 11 个模块：

| 编号 | 模块名     | 层次     | 说明                       |
| ---- | ---------- | -------- | -------------------------- |
| M01  | bsp        | 系统服务 | BSP 与系统构建             |
| M02  | drivers    | 驱动     | 外设驱动适配               |
| M03  | pipeline   | 核心业务 | 摄像头零拷贝管线           |
| M04  | ai         | 核心业务 | OCR 与离线翻译             |
| M05  | display    | 核心业务 | DRM/KMS 显示与叠加         |
| M06  | stab       | 核心业务 | 电子防抖                   |
| M07  | capture    | 核心业务 | 按键拍照与归档             |
| M08  | sensors    | 核心业务 | 自适应亮度与环境监测       |
| M09  | thermal    | 核心业务 | 温度监测与散热             |
| M10  | input      | 应用控制 | 按键事件处理               |
| M11  | comm       | 应用控制 | 进程间通信与配置           |

## 2. 各模块职责

### M01 bsp（BSP 与系统构建）
- 负责 U-Boot、Kernel、Buildroot 的定制与构建
- 设备树编写与 Overlay 管理
- 系统分区与根文件系统生成

### M02 drivers（外设驱动）
- IMX415 摄像头 V4L2 驱动
- AP3216C/ICM42688/ADT7410 的 IIO 驱动
- PWM 风扇驱动
- 按键 Input 驱动

### M03 pipeline（零拷贝管线）
- V4L2 采集管理
- DMA-BUF 缓冲池管理
- RGA 图像处理调度
- 管线状态机与帧同步

### M04 ai（OCR 与翻译）
- RKNN 模型加载与推理
- 文字检测与识别
- 离线翻译引擎
- 翻译结果排版

### M05 display（DRM 显示与叠加）
- DRM/KMS 初始化
- Plane 管理（视频层 + OSD 层）
- VSync 同步显示
- OSD 文本渲染

### M06 stab（电子防抖）
- ICM42688 IMU 数据采集
- 帧时间戳与 IMU 时间戳对齐
- 抖动补偿计算
- RGA 变换参数输出

### M07 capture（按键拍照与归档）
- 拍照模式状态机
- 高分辨率帧捕获
- 翻译结果图像合成
- 归档存储（JPG+TXT）

### M08 sensors（自适应亮度）
- AP3216C 环境光数据采集
- 显示亮度调节（背光 PWM）

### M09 thermal（温度监测与散热）
- ADT7410 温度采集
- 温度-风扇转速策略
- PWM 风扇调速
- 过温保护

### M10 input（按键事件处理）
- 按键事件读取（evdev）
- 事件去抖与分发
- 模式切换触发

### M11 comm（进程间通信与配置）
- 配置文件加载与管理
- 运行时参数调整
- 状态查询接口

## 3. 依赖关系矩阵

### 3.1 依赖表（行依赖列）

| 依赖↓\被依赖→ | bsp | drv | pipe | ai | disp | stab | cap | sen | thm | inp | comm |
| -------------- | --- | --- | ---- | -- | ---- | ---- | --- | --- | --- | --- | ---- |
| bsp            | -   |     |      |    |      |      |     |     |     |     |      |
| drivers        | ✓   | -   |      |    |      |      |     |     |     |     |      |
| pipeline       | ✓   | ✓   | -    |    |      |      |     |     |     |     |      |
| ai             | ✓   |     | ✓    | -  |      |      |     |     |     |     |      |
| display        | ✓   | ✓   | ✓    | ✓  | -    |      |     |     |     |     |      |
| stab           | ✓   | ✓   | ✓    |    |      | -    |     |     |     |     |      |
| capture        | ✓   |     | ✓    | ✓  | ✓    |      | -   |     |     | ✓   |      |
| sensors        | ✓   | ✓   | ✓    |    | ✓    |      |     | -   |     |     |      |
| thermal        | ✓   | ✓   |      |    |      |      |     |     | -   |     |      |
| input          | ✓   | ✓   |      |    |      |      |     |     |     | -   |      |
| comm           | ✓   |     |      |    |      |      |     |     |     |     | -    |

### 3.2 依赖说明

- **bsp** 是所有模块的基础（内核与系统）
- **drivers** 被 pipeline/stab/sensors/thermal/input 依赖（硬件访问）
- **pipeline** 是核心，被 ai/display/stab/capture/sensors 依赖
- **ai** 依赖 pipeline 获取帧，被 display/capture 依赖
- **display** 依赖 pipeline 获取显示帧，依赖 ai 获取 OSD 内容
- **comm** 独立于业务模块，提供配置服务

## 4. 接口边界

### 4.1 模块间通信方式

| 通信方式       | 使用场景                         |
| -------------- | -------------------------------- |
| DMA-BUF fd     | 图像数据传递（pipeline↔各模块） |
| 回调函数       | 事件通知（帧就绪、OCR 完成）     |
| 共享数据结构   | 配置参数、状态                   |
| 线程安全队列   | 异步任务（翻译请求）             |

### 4.2 关键接口边界

| 接口            | 提供方    | 使用方              | 传递内容         |
| --------------- | --------- | ------------------- | ---------------- |
| pipeline_get_frame | pipeline | ai/display/stab    | DMA-BUF fd       |
| ai_ocr_infer    | ai        | capture/display     | OCR 文本结果     |
| stab_get_transform | stab    | pipeline/display    | RGA 变换参数     |
| sensors_get_light | sensors  | display             | 环境光数据（背光调节） |
| thermal_get_temp | thermal   | comm                | 温度数据         |
| input_get_event | input     | capture/main        | 按键事件         |
