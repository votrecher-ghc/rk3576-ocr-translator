## 1. 设计目标

- 图像数据全程以 DMA-BUF fd 形式传递，**零次 CPU 拷贝**
- 仅在 AI 推理环节做必要的格式转换（NV12→RGB888）
- V4L2 采集、RGA 处理、DRM 显示三者通过 DMA-BUF 直接共享

---

## 2. 全链路架构

```
        DMA-BUF fd (NV12)           DMA-BUF fd (NV12)        DRM FB
V4L2 ──────────────────────► RGA ──────────────────────► DRM/KMS ──► 屏幕
  │   (VIDIOC_EXPBUF)          (rga_import/rga_process)     (drmModeAddFB2)
  │
  │  DMA-BUF fd (NV12)         DMA-BUF fd (RGB888)
  └────────────────────► RGA ──────────────────────► RKNN ──► OCR文本
      (导入采集fd)            (格式转换)           (rknn_set_fd)
```

## 3. V4L2 采集环节

### 3.1 采集配置

```c
// 1. 打开设备
int fd = open("/dev/video0", O_RDWR);

// 2. 设置格式
struct v4l2_format fmt = {
    .type = V4L2_BUF_TYPE_VIDEO_CAPTURE_MPLANE,
    .fmt.pix_mp.width = 1920,
    .fmt.pix_mp.height = 1080,
    .fmt.pix_mp.pixelformat = V4L2_PIX_FMT_NV12,
};
ioctl(fd, VIDIOC_S_FMT, &fmt);

// 3. 请求缓冲（使用 MMAP 方式，后续导出为 DMA-BUF）
struct v4l2_requestbuffers req = {
    .count = 4,
    .type = V4L2_BUF_TYPE_VIDEO_CAPTURE_MPLANE,
    .memory = V4L2_MEMORY_MMAP,
};
ioctl(fd, VIDIOC_REQBUFS, &req);
```

### 3.2 导出 DMA-BUF

```c
// 4. 分配并映射缓冲
for (int i = 0; i < 4; i++) {
    struct v4l2_buffer buf = {.type = ..., .memory = V4L2_MEMORY_MMAP, .index = i};
    ioctl(fd, VIDIOC_QUERYBUF, &buf);

    // mmap 到用户空间（仅用于 RGA/RKNN 访问，不拷贝）
    void *ptr = mmap(NULL, buf.length, PROT_READ|PROT_WRITE, MAP_SHARED, fd, buf.m.offset);

    // 导出为 DMA-BUF fd（关键：零拷贝的基础）
    struct v4l2_exportbuffer expbuf = {.type = ..., .index = i};
    ioctl(fd, VIDIOC_EXPBUF, &expbuf);
    // expbuf.fd 即为 DMA-BUF fd，可传给 RGA/DRM/RKNN
}

// 5. 入队开始采集
for (int i = 0; i < 4; i++) {
    struct v4l2_buffer buf = {...};
    ioctl(fd, VIDIOC_QBUF, &buf);
}
ioctl(fd, VIDIOC_STREAMON, &type);
```

## 4. RGA 处理环节

### 4.1 RGA 导入 DMA-BUF

```c
// RGA 导入 V4L2 导出的 DMA-BUF fd
rga_buffer_t src = wrapbuffer_fd(v4l2_dmabuf_fd, 1920, 1080, RK_FORMAT_YCbCr_420_SP);
```

### 4.2 RGA 处理（缩放+格式转换）

```c
// 显示路：缩放到屏幕分辨率（仍为 NV12）
rga_buffer_t dst_disp = wrapbuffer_fd(disp_dmabuf_fd, 1280, 720, RK_FORMAT_YCbCr_420_SP);
imresize(src, dst_disp);  // 硬件加速，无 CPU 拷贝

// OCR 路：缩放+格式转换（NV12 → RGB888）
rga_buffer_t dst_ocr = wrapbuffer_fd(ocr_dmabuf_fd, 320, 320, RK_FORMAT_RGBA_8888);
imcvtcolor(src, dst_ocr);  // 硬件格式转换
```

## 5. DRM/KMS 显示环节

### 5.1 DMA-BUF 导入为 Framebuffer

```c
// 将 RGA 输出的 DMA-BUF fd 导入为 DRM framebuffer
uint32_t fb_id;
drmModeAddFB2(drm_fd, 1280, 720,
              DRM_FORMAT_NV12,
              handles, pitches, offsets, &fb_id, 0);
```

### 5.2 PageFlip 显示

```c
// 设置 Plane 显示该 framebuffer
drmModeSetPlane(drm_fd, plane_id, crtc_id, fb_id, 0,
                0, 0, 1280, 720,   // 目标位置
                0, 0, 1280 << 16, 720 << 16);  // 源位置

// VSync 同步 PageFlip
drmModePageFlip(drm_fd, crtc_id, fb_id, DRM_MODE_PAGE_FLIP_EVENT, NULL);
drmHandleEvent(drm_fd, &evctx);  // 等待 VSync
```

## 6. RKNN 推理环节

### 6.1 RKNN 导入 DMA-BUF

```c
// RKNN 支持直接使用 DMA-BUF fd 作为输入（零拷贝）
rknn_input input;
input.buf = NULL;
input.fd = ocr_dmabuf_fd;  // 直接传入 DMA-BUF fd
input.type = RKNN_TENSOR_UINT8;
input.fmt = RKNN_TENSOR_NHWC;
input.size = 320 * 320 * 3;

rknn_inputs_set(ctx, 1, &input);
```

### 6.2 推理与输出

```c
rknn_run(ctx, NULL);

rknn_output output;
rknn_outputs_get(ctx, 1, &output, NULL);
// output.buf 包含 OCR 结果
```

## 7. 关键API调用序列

### 7.1 初始化序列

```
1. V4L2: open → S_FMT → REQBUFS → QUERYBUF(mmap) → EXPBUF(获取DMA-BUF fd) → QBUF → STREAMON
2. RGA:  wrapbuffer_fd(导入采集fd) + 分配目标DMA-BUF(ION/CMA)
3. DRM:  open → resources → CRTC/Connector/Plane → AddFB2
4. RKNN: rknn_init → rknn_set_io_attributes
```

### 7.2 运行时循环

```
Loop:
  1. V4L2: VIDIOC_DQBUF  (获取已采集帧的索引)
  2. RGA:  imresize(src_fd → disp_fd)   // 显示路
  3. RGA:  imcvtcolor(src_fd → ocr_fd)  // OCR路
  4. DRM:  AddFB2(disp_fd) → SetPlane → PageFlip → HandleEvent(VSync)
  5. RKNN: inputs_set(ocr_fd) → run → outputs_get
  6. Translate + OSD render
  7. V4L2: VIDIOC_QBUF  (归还缓冲，继续采集)
```

### 7.3 零拷贝验证点

| 环节     | 验证方法                                   |
| -------- | ------------------------------------------ |
| V4L2→RGA | RGA 使用 wrapbuffer_fd 而非 wrapbuffer_virtual |
| RGA→DRM  | DRM 使用 AddFB2 传入 DMA-BUF handle        |
| RGA→RKNN | RKNN 使用 input.fd 而非 input.buf          |
| 全程     | 无 memcpy 调用                             |
