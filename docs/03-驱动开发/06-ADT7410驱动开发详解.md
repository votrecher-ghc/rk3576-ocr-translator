## 1. 芯片简介

ADT7410 是 ADI 的高精度数字温度传感器，I2C 接口，16-bit 分辨率，精度 ±0.5°C。本项目用于板载温度监测与散热控制。

- I2C 地址：0x48
- 量程：-55°C ~ +150°C
- 分辨率：0.0078°C（16-bit）

## 2. 硬件连接

| ADT7410 | RK3576 |
| ------- | ------ |
| SCL     | 当前 overlay 候选：I2C4_SCL |
| SDA     | 当前 overlay 候选：I2C4_SDA |
| CT/INT  | 未连接 |

> 上表是早期接线示例。实际 I2C 控制器和供电名称必须按原理图与 vendor base DTS
> 核对，并与 `adt7410.dtso` 保持一致。

## 3. DTS 配置

```dts
&i2c4 {
    adt7410@48 {
        compatible = "ocr,adt7410";
        reg = <0x48>;
        status = "okay";
    };
};
```

## 4. 驱动实现

实际 IIO 实现位于 `bsp/kernel/drivers/iio_adt7410.c`。16-bit 模式下，scale 为
精确的 `125/16 = 7.8125 m°C/LSB`，offset 为 0，并同时暴露：

- `in_temp_raw`、`in_temp_scale`、`in_temp_offset`；换算公式为
  `(raw + offset) * scale`，结果单位是毫摄氏度。
- `in_temp_input`；直接返回同一换算结果。

Linux 内核也有面向 hwmon 的 ADT7410 支持，但不能在同一 I2C 地址与本项目 IIO
驱动同时绑定。部署时必须选择一种 ABI，并让应用配置与之匹配。

## 5. 用户态访问

```bash
# 按 name 定位并读取温度（毫摄氏度）
TEMP="$(for d in /sys/bus/iio/devices/iio:device*; do
    [ "$(cat "$d/name" 2>/dev/null)" = adt7410 ] && printf '%s\n' "$d"
done)"
[ -n "$TEMP" ] || exit 1
cat "$TEMP/in_temp_input"
# 示例输出: 35250 表示 35.25°C
```
