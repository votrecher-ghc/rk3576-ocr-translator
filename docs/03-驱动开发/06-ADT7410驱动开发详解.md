## 1. 芯片简介

ADT7410 是 ADI 的高精度数字温度传感器，I2C 接口，16-bit 分辨率，精度 ±0.5°C。本项目用于板载温度监测与散热控制。

- I2C 地址：0x48
- 量程：-55°C ~ +150°C
- 分辨率：0.0078°C（16-bit）

## 2. 硬件连接

| ADT7410 | RK3576 |
| ------- | ------ |
| SCL     | I2C2_SCL |
| SDA     | I2C2_SDA |
| CT/INT  | 未连接 |

## 3. DTS 配置

```dts
&i2c2 {
    adt7410@48 {
        compatible = "adi,adt7410";
        reg = <0x48>;
        status = "okay";
    };
};
```

## 4. 驱动实现

```c
static int adt7410_read_raw(struct iio_dev *indio_dev,
                            struct iio_chan_spec const *chan,
                            int *val, int *val2, long mask)
{
    struct i2c_client *client = to_i2c_client(indio_dev->dev.parent);
    int ret = i2c_smbus_read_word_swapped(client, ADT7410_REG_TEMP);
    // 16-bit 有符号数，乘以 1000 得到毫摄氏度
    *val = sign_extend32(ret, 15) * 1000 / 128;
    return IIO_VAL_INT;
}

static const struct iio_chan_spec adt7410_channels[] = {
    {
        .type = IIO_TEMP,
        .info_mask_separate = BIT(IIO_CHAN_INFO_RAW),
    },
};
```

> 内核已有 `adi,adt7410` 驱动（`drivers/iio/temperature/adt7410.c`），直接使用即可。

## 5. 用户态访问

```bash
# 读取温度（毫摄氏度）
cat /sys/bus/iio/devices/iio:device2/in_temp_input
# 示例输出: 35250 表示 35.25°C
```
