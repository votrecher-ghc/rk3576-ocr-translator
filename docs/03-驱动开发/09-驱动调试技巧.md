## 1. 调试工具

| 工具          | 用途                          |
| ------------- | ----------------------------- |
| dmesg         | 查看内核日志                  |
| devmem        | 直接读写寄存器                |
| i2cdetect     | I2C 设备探测                  |
| i2cget/set    | I2C 寄存器读写                |
| v4l2-ctl      | V4L2 设备控制                 |
| evtest        | Input 事件测试                |
| gpio-get/set  | GPIO 读写                     |
| debugfs       | 内核调试文件系统              |

## 2. 内核日志

```bash
# 动态调试
echo 'file imx415.c +p' > /sys/kernel/debug/dynamic_debug/control
dmesg -w  # 实时查看

# 调试级别
echo 8 > /proc/sys/kernel/printk
```

## 3. 设备树验证

```bash
# 查看已加载的设备树
ls /proc/device-tree/
# 查看节点属性
hexdump /proc/device-tree/i2c@*/ap3216c@1e/compatible
# 查看已加载的 overlay
cat /sys/kernel/config/device-tree/overlays/*/status
```

## 4. I2C/SPI 调试

```bash
# I2C 探测
i2cdetect -y 2
# 读取寄存器
i2cget -y 2 0x1e 0x0c w
# SPI 调试（spi-tools）
spi-config -d /dev/spidev0.0 -m 1000000 -s 0
```

## 5. IIO 调试

```bash
# 查看所有 IIO 设备
ls /sys/bus/iio/devices/
# 查看通道
cat /sys/bus/iio/devices/iio:device0/name
# 读取数据
cat /sys/bus/iio/devices/iio:device0/in_illuminance_raw
```

## 6. V4L2 调试

```bash
# 列出设备
v4l2-ctl --list-devices
# 查看能力
v4l2-ctl -d /dev/video0 --all
# 查看格式
v4l2-ctl -d /dev/video0 --list-formats-ext
# 采集测试
v4l2-ctl -d /dev/video0 --stream-mmap --stream-count=10
```

## 7. 常见问题

| 问题               | 排查方向                         |
| ------------------ | -------------------------------- |
| 驱动未加载         | 检查 defconfig、compatible 匹配  |
| I2C 通信失败       | 检查地址、上拉、pinctrl          |
| 中断无响应         | 检查 interrupt-parent、触发类型  |
| V4L2 无输出        | 检查 CSI/DPHY/ISP 链路配置       |
| DMA-BUF 分配失败   | 检查 CMA 大小、内存碎片          |
