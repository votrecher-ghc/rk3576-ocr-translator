## 1. 芯片简介

ICM42688 是 InvenSense 的 6 轴 IMU（3 轴陀螺仪 + 3 轴加速度计），SPI 接口，最高 32kHz 采样率。本项目用于电子防抖。

## 2. 硬件连接

| ICM42688 | RK3576  |
| -------- | ------- |
| CSB      | SPI0_CS |
| SCLK     | SPI0_CLK |
| SDI      | SPI0_MOSI |
| SDO      | SPI0_MISO |
| INT1     | GPIO4_A0 |

## 3. DTS 配置

```dts
&spi0 {
    status = "okay";
    icm42688@0 {
        compatible = "inv,icm42688";
        reg = <0>;
        spi-max-frequency = <10000000>;
        spi-cpha;
        interrupt-parent = <&gpio4>;
        interrupts = <RK_PA0 IRQ_TYPE_EDGE_RISING>;
        status = "okay";
    };
};
```

## 4. 驱动实现

```c
static int icm42688_read_reg(struct spi_device *spi, u8 reg, u8 *val)
{
    u8 tx = reg | 0x80;  // 读操作最高位置1
    return spi_write_then_read(spi, &tx, 1, val, 1);
}

static const struct iio_chan_spec icm42688_channels[] = {
    ICM_CHAN(GYRO_X, IIO_ANGL_VEL),
    ICM_CHAN(GYRO_Y, IIO_ANGL_VEL),
    ICM_CHAN(GYRO_Z, IIO_ANGL_VEL),
    ICM_CHAN(ACCEL_X, IIO_ACCEL),
    ICM_CHAN(ACCEL_Y, IIO_ACCEL),
    ICM_CHAN(ACCEL_Z, IIO_ACCEL),
    IIO_CHAN_SOFT_TIMESTAMP(6),
};
```

## 5. IIO Buffer 模式

- 使用 triggered buffer 实现连续高速采样
- 触发源：ICM42688 INT1 中断
- 数据格式：6 轴 + 时间戳，64 字节对齐

## 6. 用户态访问

```bash
# 启用 buffer
echo 1 > /sys/bus/iio/devices/iio:device1/scan_elements/in_anglvel_x_en
# 设置采样率
echo 1000 > /sys/bus/iio/devices/iio:device1/in_anglvel_sampling_frequency
# 启动采集
echo 1 > /sys/bus/iio/devices/iio:device1/buffer/enable
# 读取数据
cat /dev/iio:device1 | xxd
```
