## 1. 芯片简介

ICM42688 是 InvenSense 的 6 轴 IMU（3 轴陀螺仪 + 3 轴加速度计），SPI 接口，最高 32kHz 采样率。本项目用于电子防抖。

寄存器和量程以 [TDK ICM-42688-P 数据手册](https://invensense.tdk.com/wp-content/uploads/2020/04/ds-000347_icm-42688-p-datasheet.pdf) 为准。

## 2. 硬件连接

| ICM42688 | RK3576  |
| -------- | ------- |
| CSB      | SPI0_CS |
| SCLK     | SPI0_CLK |
| SDI      | SPI0_MOSI |
| SDO      | SPI0_MISO |
| INT1     | 当前 overlay 候选：GPIO0_PB2，falling |

> 上表是早期接线示例。实际 SPI 控制器、mode、GPIO、IRQ 极性和电源必须按原理图
> 与 vendor base DTS 核对，并与 `icm42688-spi.dtso` 保持一致。

## 3. DTS 配置

```dts
&spi0 {
    status = "okay";
    icm42688@0 {
        compatible = "ocr,icm42688";
        reg = <0>;
        spi-max-frequency = <24000000>;
        spi-cpha;
        spi-cpol;
        interrupt-parent = <&gpio0>;
        interrupts = <RK_PB2 IRQ_TYPE_EDGE_FALLING>;
        status = "okay";
    };
};
```

## 4. 驱动实现

实际实现位于 `bsp/kernel/drivers/iio_icm42688_spi.c`：校验 WHO_AM_I，配置
±4g/±2000dps 与 1kHz ODR，由 INT1 数据就绪中断触发 IIO pollfunc，并在
handler 中一次读取温度、三轴加速度和三轴陀螺仪。原始 16-bit 数据保持大端，
与各 channel 的 `IIO_BE` scan type 一致。

## 5. IIO Buffer 模式

- 使用 triggered buffer 实现连续高速采样
- 触发源：ICM42688 INT1 中断
- 固定 scan mask：温度 + 6 轴 + soft timestamp
- 当前 scan frame 为 24 bytes：14 bytes 传感器数据、2 bytes 时间戳对齐填充、
  8 bytes 时间戳；用户态仍按 sysfs `scan_elements/*_{type,index}` 动态推导布局
- 用户态进程锁防止多个实例同时启用同一 IIO buffer

## 6. 用户态访问

```bash
# 按 name 定位，不能假定 device 编号
IMU="$(for d in /sys/bus/iio/devices/iio:device*; do
    [ "$(cat "$d/name" 2>/dev/null)" = icm42688 ] && printf '%s\n' "$d"
done)"
[ -n "$IMU" ] || exit 1
cat "$IMU/name"
for f in "$IMU"/scan_elements/*_index "$IMU"/scan_elements/*_type; do
    printf '%s=' "${f##*/}"; cat "$f"
done
```

正常运行由 `ocr_translator` 负责启停 buffer 和读取 `/dev/${IMU##*/}`，不要与手工
读取并发操作。
