## 1. 芯片简介

AP3216C 集成环境光传感器（ALS）、接近传感器（PS）和红外 LED，I2C 接口。本项目使用 ALS 功能检测环境光照强度。

- I2C 地址：0x1E
- ALS 量程：0~65535 lux
- 16-bit 分辨率

## 2. 硬件连接

| AP3216C | RK3576 |
| ------- | ------ |
| SCL     | I2C2_SCL |
| SDA     | I2C2_SDA |
| INT     | GPIO3_A1 |

## 3. DTS 配置

```dts
&i2c2 {
    status = "okay";
    ap3216c@1e {
        compatible = "lbc,ap3216c";
        reg = <0x1e>;
        interrupt-parent = <&gpio3>;
        interrupts = <RK_PA1 IRQ_TYPE_EDGE_FALLING>;
        status = "okay";
    };
};
```

## 4. 驱动实现

### 4.1 关键寄存器

| 寄存器 | 地址 | 说明           |
| ------ | ---- | -------------- |
| SYS    | 0x00 | 系统配置       |
| ALS    | 0x0C | ALS 数据低字节|
| ALS    | 0x0D | ALS 数据高字节|

### 4.2 IIO 驱动骨架

```c
static const struct iio_chan_spec ap3216c_channels[] = {
    {
        .type = IIO_LIGHT,
        .info_mask_separate = BIT(IIO_CHAN_INFO_RAW),
        .address = AP3216C_REG_ALS_DATA,
    },
};

static int ap3216c_read_raw(struct iio_dev *indio_dev,
                            struct iio_chan_spec const *chan,
                            int *val, int *val2, long mask)
{
    // 读取 ALS 寄存器并返回 lux 值
    *val = i2c_smbus_read_word_data(client, chan->address);
    return IIO_VAL_INT;
}

static int ap3216c_probe(struct i2c_client *client)
{
    struct iio_dev *indio_dev = devm_iio_device_alloc(&client->dev, 0);
    indio_dev->channels = ap3216c_channels;
    indio_dev->num_channels = ARRAY_SIZE(ap3216c_channels);
    indio_dev->name = "ap3216c";
    indio_dev->modes = INDIO_DIRECT_MODE;
    return devm_iio_device_register(&client->dev, indio_dev);
}
```
