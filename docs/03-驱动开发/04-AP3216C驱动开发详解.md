## 1. 芯片简介

AP3216C 集成环境光传感器（ALS）、接近传感器（PS）和红外 LED，I2C 接口。本项目使用 ALS 功能检测环境光照强度。

寄存器与换算以 [AP3216C Rev0.86 数据手册](https://www.openhacks.com/uploadsproductos/datasheet_my.pdf) 为准。

- I2C 地址：0x1E
- ALS 默认量程：0~20661 lux
- ALS 数据：16-bit，默认量程下为 0.35 lux/count
- PS 数据：10-bit；`IR_OF` 置位时本次数据无效

## 2. 硬件连接

| AP3216C | RK3576 |
| ------- | ------ |
| SCL     | 当前 overlay 候选：I2C4_SCL |
| SDA     | 当前 overlay 候选：I2C4_SDA |
| INT     | 当前 overlay 候选：GPIO0_PA1，falling |

> 上表是早期接线示例，不是可直接投产的引脚结论。实际 I2C 控制器、GPIO bank、
> pinctrl、供电名称和中断类型必须与鲁班猫3原理图及 vendor base DTS 核对，并与
> `bsp/kernel/arch/arm64/boot/dts/rockchip/overlays/ap3216c.dtso` 保持一致。

## 3. DTS 配置

```dts
&i2c2 {
    status = "okay";
    ap3216c@1e {
	compatible = "ocr,ap3216c";
        reg = <0x1e>;
        interrupt-parent = <&gpio3>;
        interrupts = <RK_PA1 IRQ_TYPE_EDGE_FALLING>;
        status = "okay";
    };
};
```

## 4. 驱动实现

### 4.1 关键寄存器

| 寄存器 | 地址 | 说明           |
| ------ | ---- | -------------- |
| SYS    | 0x00 | 系统配置       |
| INT_STATUS | 0x01 | ALS/PS 中断状态（软件模式下写 1 清除） |
| INT_CLEAR_MANNER | 0x02 | 中断清除方式 |
| ALS    | 0x0C | ALS 数据低字节|
| ALS    | 0x0D | ALS 数据高字节|
| PS     | 0x0E | PS 数据低字节及 `OBJ`/`IR_OF` |
| PS     | 0x0F | PS 数据高字节及 `OBJ`/`IR_OF` |
| ALS_CFG | 0x10 | ALS 量程和中断滤波 |
| PS_CFG | 0x20 | PS 积分时间、增益和中断滤波 |
| PS_LED | 0x21 | 红外 LED 脉冲及电流比例 |

### 4.2 IIO 数据契约

实际实现位于 `bsp/kernel/drivers/iio_ap3216c.c`，不要复制旧的骨架读取代码。

- ALS 通过 `in_illuminance_raw` 与 `in_illuminance_scale` 暴露，默认换算为
  `lux = raw * 0.35`。
- PS 通过 `in_proximity_raw` 暴露相对计数，不声明虚假的物理 scale。
- PS 按 `(high[5:0] << 4) | low[3:0]` 解码；任一 `IR_OF` 置位时返回
  `-EOVERFLOW`。
- 有 IRQ 时使用软件 W1C 清除；无 IRQ 时使用芯片自动清除模式。
- Linux 6.1 使用单参数 `.probe_new` 与 `void remove` 接口。

## 5. 用户态访问

```bash
# 按 IIO name 查找，不能假定 device 编号
AP3216C="$(for d in /sys/bus/iio/devices/iio:device*; do
    [ "$(cat "$d/name" 2>/dev/null)" = ap3216c ] && printf '%s\n' "$d"
done)"
[ -n "$AP3216C" ] || exit 1
cat "$AP3216C/in_illuminance_raw"
cat "$AP3216C/in_illuminance_scale"
```
