## 1. pinctrl 子系统

- **职责**：管理 GPIO 引脚复用、上下拉、驱动强度
- **关键 API**：`pinctrl_register_mappings()`、`devm_pinctrl_get()`
- **DTS 节点**：`pinctrl-{name} { pinmux = <...>; bias-pull-up; };`
- **本项目用途**：配置 I2C/SPI/PWM/GPIO 引脚复用

## 2. GPIO 子系统

- **职责**：通用输入输出控制
- **关键 API**：`devm_gpio_request()`、`gpio_direction_input()`、`gpio_get_value()`
- **DTS**：`gpios = <&gpio3 RK_PA5 GPIO_ACTIVE_LOW>;`
- **中断**：`gpio_to_irq()`、`request_irq()`

## 3. Input 子系统

- **职责**：统一管理按键/鼠标/键盘等输入设备
- **关键 API**：`devm_input_allocate_device()`、`input_register_device()`、`input_event()`
- **事件类型**：EV_KEY、EV_ABS、EV_SYN
- **本项目用途**：按键事件上报

## 4. IIO 子系统

- **职责**：工业 I/O，统一管理 ADC/DAC/传感器
- **关键 API**：`devm_iio_device_alloc()`、`iio_device_register()`、`iio_push_to_buffers()`
- **通道**：`IIO_CHAN`、`IIO_VOLTAGE`、`IIO_TEMP`、`IIO_ANGL_VEL`
- **用户态接口**：sysfs（单次读取）、buffer（连续流）
- **本项目用途**：AP3216C/ICM42688/ADT7410 传感器

## 5. I2C 子系统

- **职责**：I2C 总线驱动与设备驱动
- **关键 API**：`i2c_register_driver()`、`i2c_transfer()`、`i2c_smbus_read_byte_data()`
- **DTS**：`&i2c2 { sensor@1e { compatible = "..."; reg = <0x1e>; }; };`
- **本项目用途**：AP3216C、ADT7410

## 6. SPI 子系统

- **职责**：SPI 总线驱动与设备驱动
- **关键 API**：`spi_register_driver()`、`spi_sync()`、`spi_write()`、`spi_read()`
- **DTS**：`&spi0 { sensor@0 { compatible="..."; reg=<0>; spi-max-frequency=<1000000>; }; };`
- **本项目用途**：ICM42688

## 7. PWM 子系统

- **职责**：PWM 输出控制
- **关键 API**：`pwm_request()`、`pwm_config(duty, period)`、`pwm_enable()`
- **用户态**：`/sys/class/pwm/pwmchipX/`
- **本项目用途**：风扇调速

## 8. V4L2 子系统

- **职责**：视频采集框架
- **关键 API**：`video_register_device()`、`vb2_queue_init()`、`vb2_buffer_done()`
- **子设备**：`v4l2_subdev`（IMX415）
- **本项目用途**：摄像头采集
