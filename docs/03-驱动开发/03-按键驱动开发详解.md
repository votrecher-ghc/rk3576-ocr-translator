## 1. 硬件连接

- 按键连接 GPIO0_A6，按下拉低（ACTIVE_LOW）
- 外部上拉电阻 + 软件去抖

## 2. 实现方案

使用内核内置 `gpio-keys` 驱动，无需自写驱动，仅需 DTS 配置。通过 Input 子系统上报 `KEY_ENTER` 事件。

## 3. DTS 配置

```dts
gpio_keys: gpio-keys {
    compatible = "gpio-keys";
    pinctrl-names = "default";
    pinctrl-0 = <&key_capture_pin>;

    button-capture {
        label = "Capture Button";
        gpios = <&gpio0 RK_PA6 GPIO_ACTIVE_LOW>;
        linux,code = <KEY_ENTER>;
        debounce-interval = <10>;
        wakeup-source;
    };
};

&pinctrl {
    key-pins {
        key_capture_pin: key-capture-pin {
            rockchip,pins = <0 RK_PA6 RK_FUNC_GPIO &pcfg_pull_up>;
        };
    };
};
```

## 4. 驱动实现

`gpio-keys` 为内核内置驱动（`drivers/input/keyboard/gpio_keys.c`），自动加载。如需自定义驱动：

```c
// 自定义按键驱动骨架（通常不需要，gpio-keys 已够用）
#include <linux/input.h>
#include <linux/gpio.h>
#include <linux/interrupt.h>

static irqreturn_t key_irq_handler(int irq, void *dev_id)
{
    struct input_dev *input = dev_id;
    int val = gpio_get_value(gpio);
    input_report_key(input, KEY_ENTER, !val);  // ACTIVE_LOW
    input_sync(input);
    return IRQ_HANDLED;
}
```
